EXPLAIN FORMAT=JSON 시각화 도구

MySQL Workbench Visual Explain 대체용 · 박스 + 화살표 구조로 실행계획 표시

① 데이터 입력
순수 JSON/TREE 텍스트 또는 CALL explain_all(...) 전체 로그 결과를 그대로 붙여넣으세요. 도구가 자동으로 파싱합니다.
💡 추천: 한번에 모든 결과를 뽑아주는 MySQL 프로시저 스크립트 (클릭) 
DELIMITER //
DROP PROCEDURE IF EXISTS explain_all //
CREATE PROCEDURE explain_all(p_query TEXT)
BEGIN
    SELECT '### START OF EXPLAIN REPORT ###' AS 'LOG';

    SELECT '--- [1. TRADITIONAL FORMAT] ---' AS 'FORMAT_TYPE';
    SET @sql_trad = CONCAT('EXPLAIN FORMAT=TRADITIONAL ', p_query);
    PREPARE stmt1 FROM @sql_trad; EXECUTE stmt1; DEALLOCATE PREPARE stmt1;

    SELECT '--- [2. JSON FORMAT] ---' AS 'FORMAT_TYPE';
    SET @sql_json = CONCAT('EXPLAIN FORMAT=JSON ', p_query);
    PREPARE stmt2 FROM @sql_json; EXECUTE stmt2; DEALLOCATE PREPARE stmt2;

    SELECT '--- [3. TREE FORMAT] ---' AS 'FORMAT_TYPE';
    SET @sql_tree = CONCAT('EXPLAIN FORMAT=TREE ', p_query);
    PREPARE stmt3 FROM @sql_tree; EXECUTE stmt3; DEALLOCATE PREPARE stmt3;
    
    SELECT '### END OF EXPLAIN REPORT ###' AS 'LOG';
END //
DELIMITER ;

-- 실행 예시: CALL explain_all('SELECT * FROM employees');
② 박스 색상 범례
const / system : 단일 행 조회 eq_ref / ref : 인덱스 조회 range / index : 부분·인덱스 스캔 ALL : 풀 테이블 스캔 gray : 연산 노드 (join / sort / group)

④ 실행 계획 종합 뷰
화살표 방향 : 하위 접근(테이블) → 상위 연산(join/sort) → 최종 결과 | 화살표 라벨 : 상단 cost · 하단 row 수
