Docs Viewer — 도움말 가이드

pages.json 자동 생성 스크립트(Python) 설정 안내 및 외부 블로그(티스토리)용 반응형 Iframe 임베드 코드 사용법을 설명한다.

1. pages.json 생성 스크립트 — 설정 항목

문서 뷰어가 디렉토리 트리를 구성할 수 있도록 저장소 내 문서를 자동 탐색하는 generate_pages.py 스크립트의 주요 설정 변수는 다음과 같다.

설정 변수 목록
변수명 기본값 타입 상세 설명
ROOT_DIR "." str 스캔을 시작할 루트 디렉토리 경로 (저장소 루트 기준).
OUTPUT_FILE "pages.json" str 스캔 결과로 생성될 출력 JSON 파일명.
EXCLUDE_FILES {"index.html", "404.html"} set 문서 트리에서 제외할 특정 파일명 (정확히 일치하는 파일 제외).
EXCLUDE_DIRS {".git", ".github", "node_modules", "_site"} set 탐색 대상에서 완전히 배제할 시스템 및 빌드 폴더명.
EXCLUDE_PREFIX "_" str 해당 문자로 시작하는 모든 파일 및 폴더를 일괄 제외 (임시/드래프트 문서 차단).
SCAN_EXTENSIONS {".html", ".htm"} set 문서 트리 목록에 등록할 대상 파일의 확장자 집합.
Python 스크립트 설정 코드: generate_pages.py
# ── pages.json 생성 스크립트 설정 ──────────────────
ROOT_DIR        = "."                               # 스캔 루트 (저장소 루트)
OUTPUT_FILE     = "pages.json"                      # 출력 파일명
EXCLUDE_FILES   = {"index.html", "404.html"}        # 제외할 파일명
EXCLUDE_DIRS    = {".git", ".github", "node_modules", "_site"}  # 제외할 폴더
EXCLUDE_PREFIX  = "_"                               # 이 문자로 시작하는 파일 및 폴더 일괄 제외
SCAN_EXTENSIONS = {".html", ".htm"}                # 스캔 대상 확장자
# ──────────────────────────────────────────────────
스크립트 동작 및 트리 생성 규칙
  • 접두사 기반 일괄 필터링: EXCLUDE_PREFIX를 "_"로 지정하면 _draft/ 폴더나 _temp.html 등의 임시 자산이 일괄 제외된다.
  • 자동 로드 메커니즘: 스크립트 실행 후 생성된 pages.json 파일이 루트에 위치하면, Docs Viewer가 이를 비동기 로드하여 사이드바 트리를 실시간 렌더링한다.
  • 계층형 폴더 트리 지원: 실제 디렉토리 계층 구조가 그대로 트리에 반영되며, 하위 폴더는 접고 펼칠 수 있는 아코디언 노드로 표시된다.
  • 빈 폴더 처리: 지정된 확장자의 HTML 문서가 없는 빈 디렉토리는 트리에 노출되지 않는다.

2. 티스토리 임베드 코드 (반응형 Iframe)

외부 블로그(티스토리 등)의 HTML 편집기에 삽입하여 문서를 원본 비율 그대로 렌더링하고, 문서 높이에 맞춰 Iframe 높이를 자동 조절하는 임베드 코드 규격이다.

임베드 코드 적용 순서
  • 티스토리 글쓰기 모드에서 [HTML 편집]을 활성화한다.
  • 아래의 HTML 및 자바스크립트 스니펫을 원하는 위치에 붙여넣는다.
  • src 속성의 URL을 실제 게시할 문서의 웹 경로로 교체한다.
  • 한 페이지에 여러 개의 Iframe을 삽입할 경우, id="myIframe"을 각 Iframe마다 고유한 ID로 변경한다.
HTML & JS — 티스토리 본문 삽입용
<p>
  <iframe src="https://quietjun.github.io/github-pages/ai/rnn/wordpiecetokenizer.html" id="myIframe" width="100%" frameborder="0" scrolling="no"></iframe>
</p>
<p data-ke-size="size16">
<script>
  window.addEventListener('message', function(e) {
    if (e.data && e.data.frameHeight) {
      document.getElementById('myIframe').style.height = e.data.frameHeight + 'px';
    } else if (e.data && e.data.height) {
      document.getElementById('myIframe').style.height = e.data.height + 'px';
    }
  });
</script>
</p>
높이 자동 조절(Auto-Resizing) 원리

문서 내부의 MutationObserver가 DOM 크기 변화를 감지하여 부모 창으로 postMessage 이벤트를 전송한다. 외부 블로그의 이벤트 수신 스크립트가 이를 전달받아 Iframe 높이를 실시간 갱신하므로, 내부 스크롤바 없이 깔끔한 단일 페이지처럼 표시된다.
