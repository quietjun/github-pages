단위별 요약

단위크기특징
Database 가변 스키마(논리) 단위 : 물리적으로는 디렉토리, 여러 테이블(파일) 포함
Tablespace(File) 가변 (.ibd) 테이블 1개 → 파일 1개 : OS 파일 시스템이 다루는 실제 단위
Extent 1MB = Page 64개 공간 할당 최소 단위 : Page를 낱개가 아닌 묶음으로 확보
Page 16KB 고정 디스크 ↔ 메모리 I/O 최소 단위 : Buffer Pool도 Page 단위로 캐싱
Row 가변 (수십~수백 byte) 실제 레코드 : 한 Page 안에 여러 Row가 순차 저장됨
핵심 포인트 Row 1건만 필요해도 최소 Page(16KB) 단위로 읽어옴 → 필요 없는 나머지 데이터까지 통째로 I/O 발생.
지난 글의 Handler_read_rnd 수치가 높다는 것 = 서로 다른 Page를 랜덤하게 계속 읽어왔다는 뜻.
