# 🎨 SVG 다이어그램 1:1 제로 스케일링(Zero-Scale) 절대 원칙

본 스킬은 기술 문서 및 교육 자료에 포함되는 모든 SVG 다이어그램 작성 시 지켜야 할 **1:1 물리적 밀착 및 픽셀 보정 절대 기준**을 정의합니다.

---

## 🚫 3대 절대 금지 규칙 (Hard Prohibitions)

1. **전역 폰트 오버라이드 금지**
   - CSS style 태그 내에 `font-size: max(14px, 1em) !important;`와 같은 전역 폰트 규격을 절대 선언하지 않는다. (SVG 내 텍스트 비율 및 위치 계산 파괴)

2. **SVG 스케일 다운/업(Scale Down/Up) 절대 금지**
   - SVG `viewBox`의 가로 너비는 HTML 부모 컨테이너의 실측 너비와 **1:1로 완전 일치**해야 한다.
   - 브라우저에 의해 SVG가 축소/확대(Scale)되면서 폰트가 왜곡되는 현상을 엄격히 금지한다.

3. **SVG `<text>` 내부 HTML 태그 사용 금지**
   - `<text>` 내부에는 `<sub>`, `<sup>`, `<div>`, `<span>` 등 HTML 태그를 삽입할 수 없다.
   - 수식/인덱스는 Unicode 특수문자(`x₁`, `x₂`, `h₁`, `h₂`, `W_hh`)를 직접 작성한다.

---

## 📐 물리적 컨테이너별 1:1 `viewBox` 가이드

HTML 부모 레이아웃 요소에 따라 SVG `viewBox` 가로값을 아래와 같이 1:1로 설정한다:

| 부모 HTML 컨테이너 | 실측 가로 너비 | 권장 SVG viewBox 설정 |
| :--- | :--- | :--- |
| 2칼럼 중 우측 (`col-md-7`) | **710px** | `viewBox="0 0 710 [높이]"` |
| 1칼럼 카드 (`col-lg-12`) | **780px** | `viewBox="0 0 780 [높이]"` |
| 최상위 넓은 영역 (`container-custom`) | **1240px** | `viewBox="0 0 1240 [높이]"` |

---

## ✏️ SVG 노드 & 폰트 레이아웃 규격

1. **원형 노드 크기 규격 (`r >= 28`)**
   - 14px~15px 폰트로 2~3글자(예: `h₁`, `h₂`, `x₁`) 입력 시 노드 반지름은 **최소 `r=28` (지름 56px)**을 확보한다.
   - `r=14` 등 소형 노드는 글자가 삐쳐나오므로 절대 금지한다.

2. **노드 텍스트 정중앙 정렬 필수 속성**
   - 원/사각형 중앙 텍스트는 반드시 아래 2가지 속성을 함께 명시한다:
     `text-anchor="middle" dominant-baseline="central"`

3. **이모지 렌더링 결함 방지**
   - SVG `<text>` 내에 OS별로 렌더링이 다른 날 이모지(`💬`, `⛔`, `💭`, `⚠️`) 직접 사용을 금지한다.
   - SVG 벡터 배지(`<rect>` + `<text>✕</text>`) 또는 FontAwesome SVG 아이콘을 사용한다.

4. **텍스트 경계 여백 (캔버스 잘림 방지)**
   - SVG 캔버스 좌측 끝 텍스트는 `text-anchor="middle"` 설정 시 좌측 잘림을 방지하기 위해 그룹 위치(`g transform="translate(X, Y)"`)의 X값을 **최소 20px 이상** 확보한다.
