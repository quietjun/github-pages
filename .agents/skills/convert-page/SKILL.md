# 📝 기존 컨텐츠 변환 지침 (Convert Page Guide)

기존 기술 문서를 원문 누락 없이 마스터 템플릿 기반 웹 문서로 리팩토링하기 위한 가이드입니다. 레이아웃과 수식 규격은 **[create-page 스킬](../create-page/SKILL.md)** 지침을 100% 동기화합니다.

---

## 🚨 3대 절대 금지 규칙 (Must NEVER Do)

1. **전역 폰트 강제 주입 금지 (`font-size: max(...) !important` 금지)**
   - 전역 CSS 폰트 오버라이드 엄금. [template.html](../create-page/resources/template.html) 타이포그래피 계층을 100% 보존한다.
2. **SVG 1:1 무축소/무확대 원칙 (Zero Scale-Down/Up)**
   - `viewBox` 너비를 부모 컨테이너 폭과 1:1 밀착(`710px`, `780px`)하여 브라우저 확대/축소를 원천 차단한다.
   - SVG 다이어그램 제작 시 **[svg-standards 스킬](../svg-standards/SKILL.md)** 지침을 항상 적용한다.
3. **SVG `<text>` 내부 HTML 태그 금지**
   - `<text>` 요소 내 `<sub>`, `<sup>`, `<div>` 태그 전면 금지.

---

## 🔄 변환 4단계 워크플로우

1. **백업 생성**: 원본 `[파일명].html`을 `[파일명]_백업.html`로 백업 후 작업 시작.
2. **원문 추출 및 재작성**: 핵심 수식, 기술 용어, 다이어그램 정보의 100% 보존 및 `create-page` 시각화 규칙 준수.
3. **무결성 검증 대조표 작성**: 최하단에 HTML Table 형식으로 원문 대조표(`| 핵심 항목 | 원문 내용 | 재작성 상태 | 일치 여부 | 변경 사유 |`) 포함.
4. **최종 승인 및 정리**: 사용자 최종 완료 승인 후 대조표 및 `[파일명]_백업.html` 삭제.
