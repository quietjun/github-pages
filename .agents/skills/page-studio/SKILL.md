# 🛠️ Page Studio — HTML 제작 & 변환 통합 워크플로우

본 스킬은 `github-pages` 프로젝트의 모든 HTML 문서(신규 작성 및 기존 변환)를 마스터 템플릿 표준에 맞춰 제작하는 **표준 5단계 실행 파이프라인**을 제공합니다.

세부 디자인/SVG/문체 규격은 **[style-standards 스킬](../style-standards/SKILL.md)** 지침을 100% 적용합니다.

---

## 📋 표준 5단계 작업 파이프라인 (Strict 5-Stage Protocol)

어떤 작업이든 반드시 다음 5단계를 순차적으로 수행해야 하며, 단계를 임의로 건너뛸 수 없습니다:

```
[1단계: 골격 세팅/백업] ➔ [2단계: 본문 작성 & 톤앤매너] ➔ [3단계: 시각화 코딩] ➔ [4단계: Linter 자동 검증] ➔ [5단계: 최종 보고/대조표]
```

### [모드 A] 신규 페이지 작성 (Create Mode)
1. **1단계: 템플릿 복제 및 메타 구성**
   - [resources/template.html](./resources/template.html)을 복사하여 대상 파일 생성.
   - 마스터 스타일시트 **`<link rel="stylesheet" href="/css/standards.css">`** 및 공통 스크립트 **`<script src="/js/standards.js"></script>`** (또는 상대경로) 필수 참조 확인.
   - 제목(`<h1>`), 메타 태그, TOC Drawer 목차 항목 1차 구성.
2. **2단계: 서술 본문 및 텍스트 작성**
   - 본문 서술 단락(`<p>`): 정갈한 문어체 평서형(`~한다.`, `~이다.`) 적용.
   - 비교 카드/불릿 목록(`<li>`)/표 내부: 간결한 **명사형 종결** 적용.
   - 주요 용어 최초 등장 시 [glossary.json](../style-standards/resources/glossary.json) 기준 표준 병기(`한글(English, Symbol)`).
3. **3단계: 시각화 및 수식 자산 코딩**
   - SVG 다이어그램은 부모 컨테이너와 1:1 제로 스케일(`710px`, `780px`, `1240px`)로 제작.
   - LaTeX(`$...$`) 대신 Unicode 및 HTML 태그(`<sub>`, `<sup>`, `<code>`) 활용.
4. **4단계: 브라우저 렌더링 및 완성도 자체 점검**
   - 폰트 계층, 레이아웃 정렬 및 동작 무결성 점검.
5. **5단계: 최종 확인 및 사용자 보고**
   - 브라우저 레이아웃 및 동작 무결성 확인 후 완료 보고.

---

### [모드 B] 기존 페이지 변환 (Convert Mode)
1. **1단계: 원본 백업 및 템플릿 복제**
   - 원본 `[파일명].html`을 `[파일명]_백업.html`로 백업 생성.
   - [resources/template.html](./resources/template.html) 구조 기반으로 대상 파일 초기화.
2. **2단계: 원문 텍스트 추출 및 문체 재작성**
   - 원문의 핵심 기술 내용과 설명을 빠짐없이 추출하여 재배치.
   - 본문 평서문어체 + 목록/카드 명사형 종결 + 용어 사전 표준 병기 적용.
3. **3단계: 시각화 및 수식 규격 변환**
   - 기존 이미지를 1:1 제로 스케일 SVG 다이어그램으로 전면 재작성.
   - KaTeX/수식 태그를 Unicode 및 HTML 태그로 변환.
4. **4단계: 브라우저 렌더링 및 완성도 자체 점검**
   - 레이아웃 및 톤앤매너 무결성 확인.
5. **5단계: 무결성 검증 대조표 작성 및 승인 후 정리**
   - 문서 최하단에 HTML Table 형식으로 원문 대조표(`| 핵심 항목 | 원문 내용 | 재작성 상태 | 일치 여부 | 변경 사유 |`) 작성.
   - **사용자가 브라우저에서 직접 확인하고 승인한 후** 대조표 및 `[파일명]_백업.html` 삭제 정리.
