구분 속도 안정성 비고
방법론 A 매우 빠름 보통 실시간 처리 최적화
방법론 B 보통 매우 높음 엔터프라이즈 권장

3. 표준 카드 및 중첩 카드 구조

카드가 중첩되더라도 본문 텍스트는 항상 기본 크기(16px)를 유지하며, 시각적 계층감은 제목과 배경색의 대비로 부여한다.

상위 그룹 컨테이너 (18px Bold)
카테고리 A (14px 라벨)
하위 카드 제목 (16px Bold)
"핵심 키워드 하이라이트 적용"
➔ 결론 요약 문구 (16px Accent)
카테고리 B (14px 라벨)
하위 카드 제목 (16px Bold)
"주변 글자와 동일 크기 유지"
➔ 가독성 100% 보존
원리 핵심 원리 및 수식 타이틀 (16px Bold)

원리 설명 문장 역시 small 태그로 축소하지 않고 기본 텍스트(16px) 크기를 유지하여 편안한 가독성을 제공한다.

3. 구현 예시 (Python Code)

가독성이 최적화된 17px Fira Code 환경에서 코드를 분석한다.

# 머신러닝 선형 회귀 샘플 코드
import numpy as np
from sklearn.linear_model import LinearRegression

def train_and_predict():
    # 1. 학습 데이터 생성
    X = np.array([[1], [2], [3], [4]])
    y = np.array([2, 4, 6, 8])

    # 2. 모델 인스턴스화 및 학습
    model = LinearRegression()
    model.fit(X, y)

    # 3. 결과 출력 (Highlight 확인)
    prediction = model.predict([[5]])
    print(f"예측 결과: {prediction}")
    return prediction

if __name__ == "__main__":
    train_and_predict()
