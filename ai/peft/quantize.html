LLM 양자화(Quantization) 핵심 시각화 가이드

부동소수점 비트 정밀도 설계와 정수(INT8)/분위수(NF4) 변환 로직 분석

이번 포스트에서는 대형 언어 모델(LLM)의 효율적인 서빙과 경량화를 위한 핵심 기술인 양자화(Quantization)의 물리적 구조와 수학적 변환 원리를 상세히 알아본다. FP32, FP16, BF16의 비트 할당 차이를 비교하고, INT8 균등 양자화 및 분위수 기반 NF4 양자화의 원리를 시각적 시뮬레이터와 함께 구현해 본다.

1. 부동소수점(Float) 규격과 메모리 한계

거대 모델의 대중적 서빙을 가로막는 근본적인 하드웨어 장벽과 가중치 압축 전략에 관한 요약이다.

LLM의 추론 성능은 파라미터 규모에 비례하여 향상된다. 그러나 파라미터가 비대해질수록 연산에 필요한 GPU 메모리(VRAM) 요구량과 하드웨어 도입 비용 또한 급격하게 증가한다. 일반적인 단일 GPU 환경(VRAM 16GB ~ 24GB)에서는 고정밀도로 구현된 수백억 파라미터급 모델을 메모리에 할당하는 것조차 불가능하다.

💡 정밀도 다운캐스팅과의 차이
  • 정밀도 다운캐스팅(Downcasting): FP32에서 FP16 또는 BF16으로 변환하는 것으로, 실수라는 성질(경사로)을 그대로 유지한 채 표현 비트 크기만 줄이는 작업이다.
  • 양자화(Quantization): 연속적인 무한한 실수 데이터를 딱딱 끊어지는 고정된 정수 범위(INT8/INT4 등)로 매핑하여 도메인 자체를 바꾸는 작업이다. (비유하자면, 눈금 없는 부드러운 경사로(실수)를 칸칸이 나뉜 계단(정수)으로 바꾸는 것과 같다.)

양자화는 바로 이처럼 표현 비트 수를 낮춤으로써 약간의 정확도 손실을 감수하고 모델의 메모리 요구량을 대폭 줄이는 기법이다.

2. 실수형 정밀도 비트 구조 비교 (FP32 vs FP16 vs BF16)

부동소수점 형식이 메모리 상에서 어떻게 저장되는지 부호(Sign), 지수(Exponent), 가수(Mantissa)의 물리적 크기를 원본 도표 이미지 형태로 직관적으로 비교한다.

데이터 포맷 물리적 비트 구조 소수점 정밀도 메모리 및 훈련 특징
FP32 (Single Precision) 32-bit (S1 / E8 / M23) 가장 높음 (약 7자리) 연산 기준이나 메모리 소모 극심으로 단일 GPU 서빙 한계
FP16 (Half Precision) 16-bit (S1 / E5 / M10) 중간 수준 (약 3~4자리) 메모리 50% 절감되나 좁은 표현 범위로 오버플로우 리스크 높음
BF16 (Brain Float 16) 16-bit (S1 / E8 / M7) 다소 낮음 (약 2자리) 메모리 50% 절감 및 넓은 수 범위 표현으로 안정적 훈련 지원

3. 정수형 균등 양자화 (INT8) 변환 원리

대칭 양자화(Symmetric Quantization) 직관적 이해

소수점이 있는 FP32 가중치 텐서를 정수 INT8 범위(-128 ~ 127)로 스케일링하여 격자화하는 프로세스의 엄밀한 변환 수식과 가공 순서이다.

대칭 양자화는 복잡한 수식 대신 '고무줄 줄자'를 덧대는 원리와 같다. 실수 범위에 맞추어 일정한 정수 눈금(-128 ~ 127)이 그려진 줄자를 늘리거나 줄여서 실수 가중치에 딱 맞물리게 매핑하는 원리이다.

INT8 실시간 양자화 변환기

FP32 값을 입력하여 INT8 이산화 값과 오차(L1 Loss)를 실시간 계산한다.

L1 평균 오차: 계산 중
• Scale 배율: 0.00
3단계 변환 과정:

1. 극단값 기준 설정: 부호 상관없이 크기가 가장 큰 실수(예: 2.8)를 범위 기준값으로 정함.

2. 배율 계산: 기준값(2.8)이 INT8 정밀도 최대 칸(127)에 닿는 배율을 구함. (예: 127 / 2.8 = 약 45.3배)

3. 정수 반올림 매핑: 실수에 배율을 곱해 부풀린 후 가까운 정수(-128 ~ 127)로 매핑함.

INT8 균등 변환의 핵심적인 오차 한계

INT8은 실수 범위를 '균등한 간격(Uniform Interval)'으로만 자를 수 있음. 이는 가중치 분포가 정밀하게 조밀되어 있지 않은 희소한 경계 부분까지 모두 똑같은 크기의 바구니로 할당해야 함을 의미함.

그 결과, 대부분의 가중치 원소가 집중되어 있는 0 주변의 미세한 값들은 다 같이 뭉개지고, 드물게 존재하는 아웃라이어(큰 값) 영역에만 넓은 바구니들이 낭비되어 복원 성능의 정확도 낙폭이 심해짐.

4. 분위수 기반 4-bit 양자화 (NF4) 변환 원리

가중치 텐서의 정규분포 분포를 기반으로 16개의 분위수 분할 경계면을 수학적으로 배치하여 오차 왜곡을 억제하는 NF4 방식의 핵심 원리이다.

The 'Magic Ruler' of NF4 (16 quantization bins)

0 주위 조밀 분할 (Dense near 0)

신경망의 매개변수는 대부분 0 주위에 기하급수적으로 몰려 분포함. 따라서 NF4는 가운데 0 주위에 눈금(Bins)을 조밀하게 배치하여 미세한 값 차이를 정교하게 검출하고 손실률을 FP16 수준으로 방어함.

꼬리 부분 희소 분할 (Sparse at tail)

가중치가 거의 없는 꼬리 영역(예: -2 이하, 2 이상)에는 양자화 Bins 간격을 극단적으로 크게 벌림. 어차피 분포 빈도가 낮으므로 눈금을 절약하여 0 주변의 고해상도 정보 보존에 눈금을 집중 분배함.

Quantile Size (비선형 간격)

NF4 실시간 양자화 변환기

FP32 값을 입력하여 분위수 기반 NF4 매핑 Bin 위치와 오차(L1 Loss)를 실시간 계산한다.

L1 평균 오차: 계산 중
• Block Scaler: 0.00
NF4 3단계 양자화 과정:

1. Block Scaler(배율) 추출: 입력된 가중치 블록의 절대값 중 최댓값(예: 2.8)을 구하여 Scaler 스케일 상수로 지정함.

2. 실수 정규화: 각 FP32 가중치를 Scaler 값으로 나누어 [-1.0 ~ 1.0] 범위 내로 부호와 정밀도를 정규화함. (예: -1.1 / 2.8 = -0.39)

3. 분위수 대표값 매핑: 정규화된 값이 16개 분위수 경계(Bins) 중 어디에 속하는지 검색하여 가장 가까운 대표값(Bin 인덱스)으로 변환함.
