LLM 파인튜닝 데이터 가공 및 포맷팅 가이드

실습 5-1 기준: 데이터셋 전처리, ChatML 포맷팅, Response-Only 학습 파이프라인 시각화

체스 학습 데이터 전처리 파이프라인 4단계

체스 원본 기보 데이터셋이 토크나이저와 학습용 마스크를 거쳐 모델에 주입되기까지의 흐름이다.

Stage 01. Raw Data

ChessInstruct 데이터셋

태스크 지시어, 체스 기보 입력, 다음 예상수 정답이 각각 개별 필드로 파편화되어 로드된다. 

{
  "task": "Predict move...",
  "input": "1. e4 e5 2. Nf3",
  "expected_output": "Nc6"
}
Stage 02. Conversational Schema

ChatML 구조화

대화형 모델(Gemma-3-it)이 인식할 수 있도록 system, user, assistant 역할군에 맞춰 가상 대화 목록 형태로 재구성한다. 

"conversations": [
  {"role": "system", "content": "..."},
  {"role": "user", "content": "1. e4..."},
  {"role": "assistant", "content": "Nc6"}
]
Stage 03. Format & Trim BOS

Chat Template 및 BOS 탈락

토크나이저 템플릿을 거쳐 특수 지시어 마커를 이식한 뒤, Unsloth 학습 충돌을 막기 위해 맨 앞의 중복 <bos> 토큰을 명시적으로 제거한다. 

<start_of_turn>system
Predict move...<end_of_turn>
<start_of_turn>user
1. e4 e5 2. Nf3<end_of_turn>
<start_of_turn>model
Nc6<end_of_turn>
Stage 04. Loss Masking

Response-Only 마스킹

질문 영역의 토큰들은 모델의 학습 레이블에서 -100 값으로 마스킹 처리하여 손실(Loss) 계산에서 무시하고, 오직 정답 출력 모델 응답부(model) 영역만 학습시킨다. 

labels = [
  -100, -100, ..., -100, // user 영역
  2412, 532, 23412       // model 영역
]
실습 5-1_PEFT_파라미터_효율적_튜닝 핵심 전처리 정답 코드 formatting_prompts_func 
def formatting_prompts_func(examples):
    convos = examples["conversations"]
    texts = [
        tokenizer.apply_chat_template(
            convo, tokenize=False, add_generation_prompt=False
        ).removeprefix('<bos>')  # 중복 BOS 토큰 제거
        for convo in convos
    ]
    return {"text": texts}

dataset = dataset.map(formatting_prompts_func, batched=True)
BOS (<bos>) 제거 사유 요약

<bos>는 HuggingFace에서 템플릿 가공 시 자동 삽입되는 문장 시작 마커 토큰이나, 실제 훈련 시에는 불필요하므로 제거한다. 제거하지 않고 SFTTrainer 등으로 묶어 학습시키면 중복으로 삽입되어 학습 성능과 속도가 저하되는 부작용을 예방하기 위함이다.

1. 대화형 템플릿 내의 가중치 마스킹 도해

원래 하나의 긴 연속된 문장이지만, 학습 대상이 아닌 질문/지시 영역은 취소선(Masked) 처리하고 오직 최종 정답인 model 응답 영역만 학습에 반영합니다.

<start_of_turn> system Predict the next move in this chess game. <end_of_turn> <start_of_turn> user 1. e4 e5 2. Nf3 Nc6 3. Bb5 <end_of_turn> <start_of_turn> model a6 <end_of_turn>
붉은 취소선: Loss 무시 (Label = -100 ❄️) 녹색 강조: Loss 계산 (실제 토큰 ID 🔥)
2. 최종 PyTorch Label 텐서 형태

토크나이저를 거쳐 생성된 내부 Label 목록입니다. 취소선 영역은 전부 -100 상수로 바뀌어 학습에서 제외됩니다. 

labels = [
  -100, -100, ..., -100, // user 영역
  2412, 532, 23412       // model 영역
]
