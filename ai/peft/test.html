LoRA — Low-Rank Adaptation 완전 이해

파인튜닝 기법의 핵심 원리인 LoRA의 개념과 동작 방식을 이해하고 실무 코드 적용 방법을 알아본다.

1. PEFT (Parameter Efficient Fine-Tuning) 란?

PEFT 정의: 사전학습된 대규모 언어 모델(LLM)을 특정 태스크에 맞게 적응시키는 기법이다. 전체 파라미터를 재학습하는 대신, 소수의 파라미터만 학습하여 시간·메모리·저장 공간을 대폭 절약한다.
구분 전체 파인튜닝 (Full Fine-Tuning) PEFT · LoRA (Parameter Efficient)
학습 대상 모든 파라미터 업데이트 (수십억 개 전부 학습) 원본 가중치 동결 및 소수 Adapter 파라미터만 학습
메모리 사용량 매우 높음 (수백 GB VRAM 요구) 낮음 — 전체 대비 1/10 (소비자용 GPU 가능)
저장 공간 ~50 GB / 모델 ~10 MB / Adapter (모델 공유, Adapter 교체)
학습 파라미터 100% 0.1 ~ 1% (학습 속도 2~3배 향상)
학습 시간 며칠 ~ 수 주 단일 GPU, 몇 시간 내
다중 태스크 어려움 (태스크마다 모델 복제 필요) 쉬움 (Adapter 교체만으로 즉시 전환)

2. Low-Rank 분해 원리

💡 핵심 발견: 사전학습된 LLM을 파인튜닝할 때, 가중치 변화(ΔW)는 낮은 내재 차원(low intrinsic dimension)을 가진다. ΔW 전체를 학습할 필요 없이, rank가 작은 두 행렬 B × A로 근사해도 충분하다.
ΔW (d × k) ≈ B (d × r) × A (r × k)    (r ≪ min(d, k))

행렬 분해 시각화 — ΔW (8×8) ≈ B (8×2) × A (2×8)

ΔW (8 × 8)
직접 학습: 64개 파라미터 전부
≈
B (8 × 2)
16개 파라미터
×
A (2 × 8)
16개 파라미터
  • Rank(계수) 개념: 행렬이 실제로 표현할 수 있는 선형 독립적인 방향의 수.
  • Rank 차원 병목: 두 행렬이 공유하는 좁은 차원(rank=2)이 병목이 되며, 파라미터 수가 64개에서 32개로 50% 절약.
  • 대형 모델 스케일: d=4096, rank=8 기준 가중치가 16.7M개에서 65K개로 99% 이상 절약.

3. 순전파 & 역전파 동작 방식

순전파 시에는 두 경로를 독립 계산 후 합산하며, 역전파 시에는 동결 가중치(W₀)의 수정을 차단한다.

4. 트랜스포머 내 LoRA 적용 위치

💡 기본 권장 사항: 일반적으로 q_proj + v_proj에만 적용해도 충분한 성능을 달성하며, 메모리 절감과 성능 간 균형이 가장 우수하다.
구조 구분 대상 프로젝션 모듈 역할 및 설명 LoRA 적용 여부

5. Adapter 활용 및 추론 방식 비교

🔗 분리 방식 (일반)

출력 = W₀·x + B·A·x
  • 두 번 계산 후 합산 수행
  • LoRA Adapter 교체 가능
  • 원본 W₀ 항상 보존
  • 여러 태스크 즉시 전환 지원
  • 계산 경로 분기로 인한 약간의 속도 저하

⚡ 병합 방식 (최적화)

W' = W₀ + B·A  ⇒  출력 = W'·x
  • 사전 합산 후 한 번 계산으로 완료
  • 추론 속도 빠름 (오버헤드 없음)
  • 원본과 동일 구조 유지
  • 병합 후 Adapter 교체 불가
  • 단일 태스크 배포에 최적화

6. LoRA 코드 사용법

Unsloth 프레임워크를 기반으로 한 모델 학습, Adapter 동적 로드 및 병합 추론 스크립트이다.

from unsloth import FastLanguageModel

# ── 1. Base Model 로드 + LoRA 설정 (한 번에) ────────────────────────────────
model, tokenizer = FastLanguageModel.from_pretrained(
    model_name="meta-llama/Llama-2-7b-hf",
    max_seq_length=2048,
    dtype=None,                # None → 자동 감지 (BF16/FP16)
    load_in_4bit=True,         # QLoRA: 4-bit 실시간 양자화 로드
)

# ── 2. LoRA Adapter 설정 ─────────────────────────────────────────────────────
model = FastLanguageModel.get_peft_model(
    model,
    r=16,                       # rank: Low-Rank 행렬 크기
    lora_alpha=32,              # scaling = alpha / r
    target_modules=["q_proj", "v_proj"],  # q + v 기본 권장
    lora_dropout=0.05,
    bias="none",
    use_gradient_checkpointing="unsloth",  # 메모리 추가 절감
    use_rslora=False,
)
model.print_trainable_parameters()
# 출력 예: trainable params: 4,194,304 / all params: 6,742,609,920 (0.06%)

# ── 3. 학습 후 Adapter 저장 (~10MB) ─────────────────────────────────────────
model.save_pretrained("./lora-adapter")
tokenizer.save_pretrained("./lora-adapter")
from unsloth import FastLanguageModel

# ── 1. 저장된 Adapter 로드 ───────────────────────────────────────────────────
model, tokenizer = FastLanguageModel.from_pretrained(
    model_name="./lora-adapter",  # 저장해둔 Adapter 경로
    max_seq_length=2048,
    dtype=None,
    load_in_4bit=True,
)

# ── 2. 추론 모드 전환 (속도 최적화 커널 활성화) ─────────────────────────────
FastLanguageModel.for_inference(model)

# ── 3. 추론 ─────────────────────────────────────────────────────────────────
inputs = tokenizer("회의록을 요약해줘: ...", return_tensors="pt").to("cuda")

outputs = model.generate(
    **inputs,
    max_new_tokens=256,
    temperature=0.7,
    do_sample=True
)
print(tokenizer.decode(outputs[0], skip_special_tokens=True))

# ── 4. 다른 Adapter로 교체 (동일 Base 재사용) ───────────────────────────────
model2, tokenizer2 = FastLanguageModel.from_pretrained(
    model_name="./lora-adapter-code",
    max_seq_length=2048, dtype=None, load_in_4bit=True,
)
# → Base Model(~16GB)은 그대로, Adapter(10MB)만 교체
from unsloth import FastLanguageModel

# ── 1. Adapter 로드 ──────────────────────────────────────────────────────────
model, tokenizer = FastLanguageModel.from_pretrained(
    model_name="./lora-adapter",
    max_seq_length=2048,
    dtype=None,
    load_in_4bit=True,
)

# ── 2. Adapter 병합 → W' = W₀ + B·A ────────────────────────────────────────
merged_model = model.merge_and_unload()
# → 일반 모델과 동일한 구조 · 추론 오버헤드 없음
# → 단, 병합 후 Adapter 교체 불가

# ── 3. 병합 모델 저장 (FP16으로 변환 후 저장) ───────────────────────────────
merged_model.save_pretrained_merged(
    "./merged-model",
    tokenizer,
    save_method="merged_16bit",    # "merged_4bit" · "lora" 옵션도 가능
)

# ── 4. 병합 모델 추론 ────────────────────────────────────────────────────────
FastLanguageModel.for_inference(merged_model)
inputs = tokenizer("회의록을 요약해줘: ...", return_tensors="pt").to("cuda")
outputs = merged_model.generate(**inputs, max_new_tokens=256)
print(tokenizer.decode(outputs[0], skip_special_tokens=True))

LoRA 핵심 정리

  • LOW-RANK 원리: ΔW = B × A (큰 행렬을 두 작은 행렬 곱으로 근사)
  • 파라미터 절감: rank=8 기준 전체 대비 99% 이상 절약
  • 원본 보존: W₀ 완전 동결 및 Adapter 교체를 통한 다중 태스크 지원
