Transfer Learning Strategy Guide

Linear Probing & Fine-tuning 전이학습 전략

사전 학습(Pre-trained) 백본 모델의 특징 추출 레이어 동결(Freeze) 범위, 파라미터 업데이트 비율, 훈련 속도 및 에포크별 성능 추이를 인터랙티브하게 비교 분석한다.

1. CNN 특징 추출 구조 & 파라미터 동결 상태

🏗️
레이어별 동결(Freeze) vs 학습(Train) 메커니즘
🔒
Linear Probing (선형 탐침) 전략
특징 추출 레이어(Conv + Pooling)를 동결(Freeze)하고, 분류층(FC Layer)만 새로 학습한다. 사전 학습된 지식을 그대로 활용하여 학습이 매우 빠르고 과적합 위험이 낮다.

2. Linear Probing vs Fine-tuning 전략 비교

⚖️
두 전략 핵심 사양 1:1 비교표
비교 항목 🔒 Linear Probing (선형 탐침) 🔥 Fine-tuning (미세 조정)
개념 정의 특징 추출 레이어 동결, 분류층(FC)만 새로 학습 사전 학습 가중치를 초기값으로 전체/일부 모델 추가 학습
학습 파라미터 ~1% (분류층만) 100% (전체 모델)
학습 속도 매우 빠름 (분 단위) 상대적으로 느림 (시간/일 단위)
권장 학습률 (Learning Rate) 0.001 ~ 0.01 (상대적으로 큼) 0.0001 ~ 0.001 (미세 조정)
과적합 위험 낮음 높음 (데이터 부족 시)
초기 정확도 (Epoch 1) ~60%+ 이상에서 시작 ~10% 수준에서 시작
최종 성능 70%+ (빠르고 준수한 성과) 90%+ (최고 성능 달성)

🔒 Linear Probing 선택 상황

  • 데이터셋 규모가 소형인 경우 (수백 ~ 수천 장)
  • 빠른 가설 검증 및 프로토타이핑 필요 시
  • 컴퓨팅 자원(GPU)이 제한적인 경우
  • 과적합(Overfitting) 방지 최우선 시
  • 원본과 대상 데이터의 도메인이 유사한 경우

🔥 Fine-tuning 선택 상황

  • 충분한 라벨링 데이터 확보 시 (수만 장 이상)
  • 최고 수준의 모델 정확도 필요 시
  • 충분한 GPU/TPU 연산 자원 보유 시
  • 원본 데이터와 타겟 도메인 간격이 큰 경우
  • 학습 시간에 여유가 있는 경우

4. 핵심 인사이트 & 연산식 요약

⚡
1. 신속한 수렴 속도
사전 학습 모델은 스크래치 대비 비약적으로 빠르게 수렴하며, Linear Probing은 분 단위 초고속 수렴 달성
🚀
2. 우수한 초기 성능
첫 에포크부터 높은 초기 정확도 달성 (Random 초기화 ~10% vs 전이학습 ~60%+ 이상)
🎯
3. 최종 성능 달성
Linear Probing만으로 70%+ 수렴하며, Fine-tuning 적용 시 90%+ 최고 정확도 확보
🧊
4. 저수준 특징 범용성
ImageNet 기반 저수준 특징(엣지·색상·질감)은 대부분의 시각 문제에 범용적 유효
🔒 LINEAR PROBING 연산식
Output = Wnew · Freeze(CNN_features(X))
분류층 Wnew만 업데이트하고, 특징 추출기 CNN_features는 완전히 동결함.
🔥 FINE-TUNING 연산식
Output = Wnew · CNN_features(X; θpretrained)
Wnew와 θ 모두 작은 학습률(Learning Rate)을 적용하여 미세하게 함께 업데이트함.
