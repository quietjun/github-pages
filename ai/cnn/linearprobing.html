① CNN 특징 추출 구조 & 파라미터 동결 상태
🏗️ 레이어별 동결(Freeze) vs 학습(Train) 구조
🔒 Linear Probing: 특징 추출 레이어(Conv + Pooling)를 동결(freeze)하고, 분류층(FC Layer)만 새로 학습합니다. 사전 학습된 지식을 그대로 활용하여 학습이 매우 빠르고 과적합 위험이 낮습니다.

🔒 Linear Probing 선택 상황

  • 데이터셋 규모가 작을 때 (수백 ~ 수천 장)
  • 빠른 가설 검증 및 프로토타이핑이 필요할 때
  • 컴퓨팅 자원(GPU)이 제한적일 때
  • 과적합(Overfitting) 방지가 최우선일 때
  • 원본 데이터와 대상 데이터의 도메인이 유사할 때

🔥 Fine-tuning 선택 상황

  • 충분한 라벨링 데이터가 확보되었을 때 (수만 장 이상)
  • 최고 레벨의 모델 정확도가 필요할 때
  • 충분한 GPU/TPU 연산 자원이 있을 때
  • 원본 데이터와 타겟 도메인의 차이가 클 때
  • 학습 시간에 여유가 있을 때
③ 학습 정확도 시뮬레이션 (CIFAR-10 기반)

④ 핵심 인사이트 & 수학적 수식 요약
💡 전이학습 핵심 관찰 포인트
⚡

1. 신속한 수렴 속도

사전 학습 모델은 처음부터 학습하는 것보다 수렴 속도가 비약적으로 빠르며, Linear Probing은 특히 분 단위로 수렴합니다.

🚀

2. 우수한 초기 성능

첫 에포크부터 높은 정확도를 보입니다. (Random 초기화 ~10% vs 전이학습 ~60%+ 이상)

🎯

3. 최종 성능 달성

Linear Probing만으로도 70%+ 수준을 달성하며, Fine-tuning 시 90%+ 이상의 최고 정확도를 확보합니다.

🧊

4. 저수준 특징의 범용성

ImageNet 등으로 학습된 엣지, 색상, 질감 등 저수준 특징은 대부분의 시각 문제에 공통으로 유용합니다.

🔒 Linear Probing 연산식
Output = W_new · Freeze(CNN_features(X))
분류층 W_new만 업데이트하고, 특징 추출기 CNN_features는 완전히 동결합니다.
🔥 Fine-tuning 연산식
Output = W_new · CNN_features(X; θ_pretrained)
W_new와 θ 모두 작은 학습률(Learning Rate)을 적용하여 미세하게 함께 업데이트합니다.
