CLIP이란 무엇인가?

OpenAI (2021) — 이미지와 언어를 동일한 벡터 공간에서 함께 이해하는 혁신적 multimodal AI 모델

💡 한 줄 요약: 사람처럼 이미지와 텍스트를 동시에 이해해, "이 사진은 고양이야" 같은 연결 고리를 수억 개의 데이터로부터 스스로 학습한 모델이다.

1. 기존 문제점 대 해결 방법 비교

기존 컴퓨터 비전 모델의 범용성 한계를 CLIP이 멀티모달 학습으로 극복한 구조를 비교한다.

❌ 기존 방식의 한계 (Supervised Learning) ✅ CLIP의 혁신적 접근 (Contrastive Learning)
  • 고정된 카테고리(예: 1,000개 클래스)만 인식 가능
  • 새로운 클래스("고양이") 추가 시 수천 장의 데이터 수집 및 재학습 필수
  • 라벨링 비용과 시간 소요가 매우 큼
  • 이미지와 텍스트 설명을 동일한 공간(Shared Vector Space)에 매핑
  • 새로운 카테도 텍스트 설명만 입력하면 추가 학습 없이 즉시 인식
  • Zero-shot 성능을 통해 라벨링 비용 대폭 절감

2. 핵심 아이디어 — 공유 임베딩 공간 매핑

이미지 인코더와 텍스트 인코더가 각각 추출한 임베딩 벡터를 하나의 다차원 공간 상에 정렬한다.

Similarity Score = CosineSimilarity(Embeddingimage, Embeddingtext) = (vimg · vtxt) / (||vimg|| ||vtxt||)

3. CLIP 학습 및 활용 3단계 절차

CLIP 모델이 데이터를 준비하고, 대조 학습을 수행하며, 최종 서비스에 활용되는 절약 프로세스이다.

Step 1
대규모 데이터 수집
  • 웹에서 이미지 + 텍스트 설명 쌍 4억 개 수집
  • 예: "고양이 사진" 텍스트와 🐱 이미지 형태 데이터 매칭
Step 2
대조 학습 (Contrastive)
  • 올바른 매칭 쌍 $\rightarrow$ 벡터 공간 거리를 가깝게(↓) 정렬
  • 틀린 쌍 $\rightarrow$ 벡터 공간 거리를 멀게(↑) 밀어냄
  • 수십억 번의 반복 대조 학습 진행
Step 3
Zero-shot 활용
  • 새로운 이미지 입력 $\rightarrow$ 후보 텍스트들과 코사인 유사도 계산
  • 가장 유사도가 높은 텍스트를 최종 선택
  • 별도의 재학습(Fine-tuning) 없이 즉시 사용 가능

4. Zero-shot 분류 동작 예시

후보 텍스트 태그 목록만 변경하면 모델의 재학습 없이 원하는 분류를 수행한다.

🐶
강아지 이미지 입력
자동차 사진 하늘 사진 강아지 사진 ✓ 음식 사진 건물 사진
🌅
일몰 풍경 이미지 입력
실내 사진 일몰 풍경 사진 ✓ 도시 야경 사진 인물 사진

※ 각 텍스트 태그를 인코더를 통해 벡터로 변환 후 이미지 벡터와 유사도를 계산해 최고점을 선택한다.

5. 왜 CLIP이 중요한가? (4대 핵심 가치)

현대 AI 생태계에서 CLIP이 핵심 기반 모델로 자리잡은 4가지 주요 이유이다.

구분 핵심 특징 세부 설명 및 파급 효과
🔓 범용성 (Generality) 특정 Task에 종속되지 않음 분류, 이미지 검색, 텍스트 기반 생성 등 다양한 비전 태스크에 공통 적용 가능
💬 언어 기반 제어 자연어로 인식 개념 지정 새 개념을 텍스트로 설명하기만 하면 되므로 데이터 수집 및 라벨링 비용 대폭 절감
🧱 생성 AI의 기반 모델 Generative Model의 핵심 인코더 DALL·E 2, Stable Diffusion 등 텍스트-이미지 생성 AI의 텍스트 조건부 조건 처리부로 사용
📏 이미지-텍스트 평가 지표 CLIP Score 활용 생성된 이미지가 프롬프트(텍스트) 설명과 얼마나 일치하는지 정량 측정하는 기준 지표가 됨

핵심 요약

  • CLIP은 이미지와 텍스트를 동일한 벡터 임베딩 공간에 매핑하는 대조 학습 모델이다.
  • 4억 개의 (이미지, 텍스트) 쌍으로 사전 학습하여 재학습 없는 Zero-shot 분류를 지원한다.
  • DALL·E 2, Stable Diffusion 등 현대 멀티모달 및 Generative AI 생태계의 핵심 기반 기술이다.
