CNN (Convolutional Neural Network)

합성곱 신경망 — 이미지를 이해하는 시각 신경망 가이드
Conv · Pooling · FC 핵심 블록의 동작 원리와 인터랙티브 픽셀 및 연산 시뮬레이션

1. 개요 및 CNN의 본질 (이미지와 숫자 행렬)

🖼️

이미지는 숫자 행렬

컴퓨터는 이미지를 픽셀 밝기값(0~255) 수치 행렬로 인지하며, 컬러 사진은 R·G·B 3채널의 3D 행렬로 표현된다.

🔍

지역적 패턴 학습

작은 필터(커널)를 슬라이딩하며 엣지, 선, 곡선 등 국소적 패턴(Local Features)을 수학적 연산으로 추출한다.

📐

공간/위치 불변성

동일한 필터 가중치를 이미지 전체 영역에 공유 적용하여, 피사체가 어느 위치에 있든 동일하게 감지한다.

🖼️ 시각적 픽셀 vs 컴퓨터의 2D 숫자 행렬 (0~255 수치)
사람이 눈으로 인식하는 시각 이미지와 컴퓨터가 실제 내부 메모리에서 처리하는 0(검은색)부터 255(흰색)까지의 픽셀 밝기 수치 행렬을 1:1 대조 시각화한다.

▲ [왼쪽] 사람이 인식하는 이미지 패턴  |  [오른쪽] 컴퓨터가 실제 처리하는 픽셀 밝기 수치 행렬

💡
MLP (다층 퍼셉트론)와 CNN의 결정적 차이
• MLP (Multi-Layer Perceptron): 2D 이미지를 1D 평탄화(Flatten)하여 입력하므로 공간적 위치 구조 정보가 완전히 손실되며 파라미터가 급격히 폭발함
• CNN (Convolutional Neural Network): 2D/3D 공간 형상을 그대로 유지하며 인접 픽셀 간 상호 연관성을 필터로 탐지함
• 파라미터 공유 (Weight Sharing): 이미지 전체 영역에 동일 필터를 슬라이딩 적용하여 학습해야 할 가중치 수치를 대폭 절감함

2. CNN 핵심 3대 빌딩 블록 (Conv · Pooling · FC)

nn.Conv2d(in_channels, out_channels, kernel_size, stride=1, padding=0)
01  Convolutional Layer · 합성곱 레이어
입력 이미지에 필터(커널)를 슬라이딩하며 요소별 곱셈 및 합산(Dot Product + Bias)을 수행하여 Feature Map (특징 맵)을 생성한다.
• 필터 1개 = 특정 형태의 엣지/패턴 감지기 역할 수행
• 기본 연산 공식:
Output = Σ(Input × Weight) + Bias

(※ 딥러닝 라이브러리 파라미터명에서 자주 사용되는 커널(Kernel)은 필터(Filter)와 동일한 대상을 지칭한다.)
❓
필터 수치는 사람이 직접 지정하나요, 아니면 스스로 학습하나요?
학습 과정에서 인공지능이 스스로 탐색하여 최적화합니다!
초기 필터 가중치는 난수(Random)로 설정되지만, 수많은 이미지를 학습(역전파, Backpropagation)하면서 이미지를 가장 잘 분류할 수 있는 수직 엣지, 곡선, 질감 등의 최적 필터 가중치를 자동으로 갱신한다.
(아래 시뮬레이션의 'Sobel/블러' 필터는 이해를 돕기 위한 예시이며, 실제 모델은 더 복잡하고 정밀한 필터를 자동 생성한다.)

📊 여러 필터 동시 적용 = 다채널 특징 맵 (Multi-Channel Feature Maps) 생성
CNN은 1개의 필터만 사용하지 않고 32개, 64개 등 수많은 필터를 동시 적용한다. 필터마다 서로 다른 형태의 패턴(수직선, 수평선, 샤프닝, 블러 등)을 감지하여 다채로운 특징 맵 레이어를 구성한다.

▲ 1개의 동일한 원본 사진 → 서로 다른 4개 필터 적용 → 감지된 특징이 각각 강조된 다채널 맵 생성

nn.MaxPool2d(kernel_size=2, stride=2)
02  Pooling Layer · 풀링 레이어
Feature Map의 해상도를 축소하는 다운샘플링 (Downsampling)을 수행하여 계산량을 절감하고 미세한 위치 변화에 강인한 표현을 형성한다.
• 2×2 영역에서 최댓값을 선택하는 Max Pooling이 대표적이다.
• 학습 파라미터 없음 (가중치 0개) — 단순 통계 집계 연산 수행
🎬 영상 1: Top Breeder (격자 재배치와 다운샘플링) 🎬 영상 2: #todayscuriosity: Avatar (사진 슬라이싱 작업)
🎬 Pooling 인터랙티브 시뮬레이터 (2×2 vs 3×3 / Max vs Avg 비교)
2×2 Max Pooling (S=2): 2×2 겹치지 않는 영역에서 가장 큰 값만 추출한다. (출력 크기: 2×2)
구분 Max Pooling Average Pooling

특징 및 효과 강한 엣지 및 선명한 특징 추출 강조 부드러운 전반적 배경 정보 유지
학습 파라미터 0개 (가중치 없음) 0개 (가중치 없음)
nn.Linear(in_features, out_features)
03  Fully Connected Layer · 완전연결 레이어
Conv와 Pooling을 거쳐 추출된 3D 특징 맵을 1차원 벡터로 펼쳐(Flatten) 최종 분류를 수행한다.
• 고수준 특징들의 조합을 바탕으로 Softmax 함수를 적용하여 각 클래스별 확률값(0~1)을 출력한다.

4. Conv & Pooling 실전 계산 예제 (Feature Map & Params)

Feature Map Shape & Parameter Calculation Example
🧮 실전 예제: Conv2d 및 Pooling 출력 크기 및 파라미터 개수 계산
입력 이미지 32 × 32 × 3 (H × W × C)에 대해 Conv2d 및 Max Pooling 연산을 적용할 때의 출력 크기 (Feature Map Shape), 채널 수, 학습 파라미터 개수 (Parameters) 단계별 계산 과정이다.
🔲 1. Convolutional Layer (Conv2d)
• 입력 크기: 32 × 32 × 3 (Hin=32, Win=32, Cin=3)
• 설정 조건: 커널 K=3×3, Stride S=1, Padding P=1, 출력 채널 Cout=8
• 출력 가로/세로 크기 산출 공식:
   Hout = ⌊(32 + 2×1 - 3) / 1⌋ + 1 = 32
   Wout = ⌊(32 + 2×1 - 3) / 1⌋ + 1 = 32
• 출력 채널 수 (Cout): 설정한 필터 개수 = 8 채널
• 학습 파라미터 (Params) 수 계산:
   ((3 × 3 × 3) + 1) × 8 = 224 개
🎯 [Conv2d 최종 결과]
• Feature Map Shape: 32 × 32 × 8
• 채널 수: 8 채널  |  파라미터 수: 224 개
⬇️ 2. Max Pooling Layer (2×2, Stride=2)
• 입력 크기: 32 × 32 × 8 (Conv 연산의 출력값)
• 설정 조건: 커널 2×2, Stride 2 (표준 다운샘플링)
• 출력 H, W 크기 계산:
   Hout = ⌊(32 - 2) / 2⌋ + 1 = 16
   Wout = ⌊(32 - 2) / 2⌋ + 1 = 16
• 출력 채널 수 계산: Cout = Cin = 8 채널 (동일 유지)
• 학습 파라미터 (Params) 수: 0 개 (학습 가중치 없음)
🎯 [Pooling 최종 결과]
• Feature Map Shape: 16 × 16 × 8
• 채널 수: 8 채널  |  파라미터 수: 0 개
💡
한눈에 보는 계산 정답 요약
• Conv2d 최종 출력 = 32 × 32 × 8  (채널 수: 8개 / 파라미터 수: 224개)
• Pooling 최종 출력 = 16 × 16 × 8  (채널 수: 8개 / 파라미터 수: 0개)

5. CNN이 강력한 4가지 핵심 원리

🔗 1. 지역 연결성 (Local Connectivity)

모든 픽셀을 전결합하지 않고 3×3 등 작은 국소 영역 (Receptive Field)에만 뉴런을 연결함으로써 연산량과 파라미터를 비약적으로 절감한다.

⚖️ 2. 가중치 공유 (Weight Sharing)

하나의 필터 가중치를 이미지 전체 위치에 동일하게 슬라이딩하며 적용한다. 세로선 패턴을 학습하면 영상 어느 위치든 감지할 수 있다.

📚 3. 계층적 학습 (Hierarchical Features)

층이 깊어질수록 단순 엣지 → 복잡한 모양 → 고수준 객체 부위로 추상화 수준이 높아진다. 사람의 시각 피질 작동 원리와 일치한다.

🎯 4. 이동 불변성 (Translation Invariance)

합성곱 연산과 Pooling 축소를 거치며 피사체가 중앙, 좌측, 우측 등 어느 위치로 이동하더라도 동일하게 인식하는 강인성을 가진다.

6. PyTorch 모델 구현 코드 (CNN Sample)

PyTorch의 torch.nn.Module을 상속하여 특징 추출(Feature Extraction) 및 분류(Classification) 파이프라인을 갖춘 CNN 모델 클래스 구현 예제이다.

import torch
import torch.nn as nn
import torch.nn.functional as F

class SimpleCNN(nn.Module):
    def __init__(self, num_classes=10):
        super(SimpleCNN, self).__init__()
        # 1. 첫 번째 합성곱 블록 (Conv2d -> ReLU -> MaxPool)
        self.conv1 = nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3, stride=1, padding=1)
        self.pool1 = nn.MaxPool2d(kernel_size=2, stride=2)
        
        # 2. 두 번째 합성곱 블록
        self.conv2 = nn.Conv2d(in_channels=16, out_channels=32, kernel_size=3, stride=1, padding=1)
        self.pool2 = nn.MaxPool2d(kernel_size=2, stride=2)
        
        # 3. 완전연결 레이어 (Fully Connected)
        # 32x32x3 입력 기준 -> pool2 거치면 8x8x32 차원
        self.fc1 = nn.Linear(32 * 8 * 8, 128)
        self.fc2 = nn.Linear(128, num_classes)

    def forward(self, x):
        # 특징 추출 파트 (Feature Extraction)
        x = self.pool1(F.relu(self.conv1(x)))
        x = self.pool2(F.relu(self.conv2(x)))
        
        # 1D 벡터 평탄화 (Flatten)
        x = x.view(x.size(0), -1)
        
        # 최종 분류 파트 (Classification)
        x = F.relu(self.fc1(x))
        x = self.fc2(x)
        return x

if __name__ == "__main__":
    # 샘플 입력 (Batch=1, Channels=3, H=32, W=32)
    dummy_input = torch.randn(1, 3, 32, 32)
    model = SimpleCNN(num_classes=10)
    output = model(dummy_input)
    print(f"모델 출력 Shape: {output.shape}") # [1, 10]

7. 핵심 요약

  • CNN은 2D/3D 공간 구조를 보존하며 커널 슬라이딩을 통해 이미지를 효과적으로 이해한다.
  • Conv (합성곱) 레이어는 국소 패턴 추출, Pooling (풀링)은 다운샘플링 및 가중치 절감 역할을 수행한다.
  • Weight Sharing (가중치 공유)과 Local Connectivity (지역 연결성) 덕분에 학습 파라미터가 크게 감소한다.
  • 추출된 3D 특징 맵은 Flatten & FC Layer를 거쳐 최종 클래스 확률로 예측된다.
