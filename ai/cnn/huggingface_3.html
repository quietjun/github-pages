Part 3. Multimodal Contrastive Foundation Model

CLIP Zero-shot 분류

OpenAI에서 개발한 CLIP(Contrastive Language-Image Pre-training) 멀티모달 대조 학습 알고리즘, 공유 임베딩 공간 구조 및 파이썬 추론 코드를 학습한다.

1. CLIP 개념 & 멀티모달 임베딩 공간

🧩
CLIP 멀티모달 대조 학습 메커니즘
💡
CLIP 핵심 요약
이미지와 텍스트를 동시에 이해하여 "이 사진은 고양이다"라는 연관 관계를 4억 개의 데이터 쌍으로 대조 학습한 멀티모달(Multimodal) AI 파운데이션 모델이다.
❌ 기존 정통 CNN의 한계
사전에 지정된 고정 카테고리(예: ImageNet 1,000개 클래스)만 정적으로 분류 가능하며, 새로운 카테고리를 인식하려면 수천 장의 데이터 수집과 FC 레이어 재학습이 필수적이다.
✅ CLIP의 해결책 (멀티모달 대조학습)
이미지와 텍스트를 공유 임베딩 공간(Joint Space)에 함께 투영하여 학습시켰으므로, 처음 보는 카테고리도 텍스트 레이블 리스트만 전달하면 재학습 없이 **Zero-shot 분류**를 수행한다.

2. CLIP 3단계 작동 과정 & Zero-shot 분류 예시

🔄
CLIP 작동 절차 3단계 & 분류 매칭 예시

🔄 CLIP 핵심 작동 과정 3단계

1
대규모 데이터 쌍 수집
인터넷에서 이미지와 설명을 쌍으로 이룬 4억 개의 방대한 데이터 쌍 사전 수집
2
대조 학습 (Contrastive)
일치하는 쌍의 거리는 좁히고, 일치하지 않는 가짜 쌍들의 거리는 멀게 배치하도록 수십억 번 최적화
3
Zero-shot 분류 활용
처음 보는 이미지도 후보 텍스트 레이블과의 거리를 공통 공간에서 연산하여 가장 가까운 텍스트를 정답 클래스로 분류

🧩 Zero-shot 분류 시뮬레이션 예시

사전 학습 데이터에 정형화된 레이블이 없어도, 텍스트 후보 리스트만 제공하면 CLIP이 적절한 대상을 자동 매칭한다.

3. CLIP 핵심 실행 코드 예제

💻
PyTorch & Transformers 기반 CLIP 추론 코드
Hugging Face transformers 라이브러리를 사용해 CLIP 모델을 로드하고 이미지-텍스트 유사도 및 확률을 연산하는 소스 코드이다.

🔗 Hugging Face - openai/clip-vit-base-patch32 모델 페이지 바로가기 
from PIL import Image
import requests
from transformers import CLIPProcessor, CLIPModel

# 1. CLIP 모델 ID 정의 및 모델/프로세서 로드
model_id = "openai/clip-vit-base-patch32"
model = CLIPModel.from_pretrained(model_id)
processor = CLIPProcessor.from_pretrained(model_id)

# 2. 샘플 이미지 다운로드 및 로드
url = "http://images.cocodataset.org/val2017/000000039769.jpg"
image = Image.open(requests.get(url, stream=True).raw)

# 3. 텍스트 레이블 후보와 이미지 전처리 진행
inputs = processor(
    text=["a photo of a cat", "a photo of a dog"],
    images=image,
    return_tensors="pt",  # PyTorch 텐서로 반환
    padding=True           # 문장 길이를 맞추기 위해 패딩 추가
)

# 4. 모델 추론 진행
outputs = model(**inputs)                   # **inputs: 딕셔너리를 키워드 인자(kwargs)로 언패킹 전달
logits_per_image = outputs.logits_per_image # 이미지-텍스트 코사인 유사도 점수
probs = logits_per_image.softmax(dim=1)     # Softmax 취해 레이블 확률 분포 계산

print(f"고양이 확률: {probs[0][0].item()*100:.2f}% | 개 확률: {probs[0][1].item()*100:.2f}%")
