CNN (Convolutional Neural Network)

합성곱 신경망 — 이미지를 이해하는 시각 신경망 가이드
Conv · Pooling · FC 핵심 블록의 원리와 인터랙티브 시각화

① CNN이란? (이미지의 본질)
🖼️

이미지는 숫자 행렬

컴퓨터는 이미지를 픽셀 밝기값(0~255) 행렬로 인지합니다. 컬러 사진은 R·G·B 3채널의 3D 행렬로 표현됩니다.

🔍

지역적 패턴 학습

작은 필터(커널)를 슬라이딩하면서 엣지, 선, 곡선 등 국소적 패턴(Local Features)을 연산으로 추출합니다.

📐

공간/위치 불변성

동일한 필터 가중치를 이미지 전체 영역에 공유 적용하여, 객체가 이미지 내 어디에 있든 동일하게 감지합니다.

🖼️ 시각적 픽셀 vs 컴퓨터의 2D 숫자 행렬 (0~255)
우리가 눈으로 보는 이미지는 컴퓨터 내부에서 각 위치마다 0(검은색)부터 255(흰색)까지의 픽셀 밝기 수치로 변환되어 저장됩니다.

▲ [왼쪽] 사람이 인식하는 이미지 패턴  |  [오른쪽] 컴퓨터가 실제 처리하는 픽셀 밝기 수치 행렬

💡
MLP(다층 페셉트론)와 CNN의 결정적 차이
MLP → 2D 이미지를 1D 평탄화(Flatten)하여 입력 : 공간적 위치 구조 정보가 완전히 손실됨
CNN → 2D/3D 형상을 그 대로 유지 + 인접 픽셀 간 상호 관계를 필터로 탐지
파라미터 공유(Weight Sharing) → 이미지 전체에 동일 필터를 슬라이딩하여 가중치 수 대폭 절감
② Conv · Pooling · FC — 3가지 빌딩 블록
nn.Conv2d(in_channels, out_channels, kernel_size, stride=1, padding=0)
01  Convolutional Layer · 합성곱 레이어
입력 이미지에 필터(커널)를 슬라이딩하며 요소별 곱셈 및 합산(Dot Product + Bias)을 수행해 Feature Map(특징 맵)을 생성합니다.
→ 필터 하나 = 하나의 특정한 엣지/패턴 감지기
→ 기본 연산식: output = Σ(input × weight) + bias
(※ 수학적으로 필터를 반전하지 않고 원소별로 바로 곱해 더하는 연산은 교차 상관(Cross-Correlation)에 해당하나, 딥러닝 분야에서는 이를 통칭하여 합성곱(Convolution) 연산이라 부릅니다.)

학습 과정에서 스스로 찾아냅니다!

📊 여러 필터 동시 사용 = 다양한 다채널 특징 맵(Feature Maps) 생성
CNN은 1개의 필터만 쓰지 않고 32개, 64개 등 수많은 필터를 동시 적용합니다. 필터마다 서로 다른 형태의 패턴(수직선, 수평선, 선명함, 부드러움 등)을 감지해 다채로운 특징 맵 레이어를 구성합니다.

02  Pooling Layer · 풀링 레이어
Feature Map의 해상도를 축소하여 다운샘플링(Downsampling)을 수행함으로써 계산량을 크게 절감하고 위치 변화에 강인한 표현을 형성합니다.
→ 2×2 영역에서 최댓값을 선택하는 Max Pooling이 가장 대표적입니다.
→ 학습 파라미터 없음 (가중치 0개) — 단순 집계 연산 수행

⑤ CNN이 강력한 4가지 핵심 원리
🔗 1. 지역 연결성 (Local Connectivity)
일반 신경망(MLP)처럼 모든 픽셀을 전체 뉴런에 연결하지 않고, 3×3 등 **작은 국소 영역(Receptive Field)**만 뉴런에 연결합니다. 이로 인해 연산량과 파라미터가 비약적으로 감소합니다.
⚖️ 2. 가중치 공유 (Weight Sharing)
하나의 필터 가중치를 **이미지 전체 위치에 동일하게 슬라이딩**하며 적용합니다. 필터 하나가 특정 패턴(예: 세로선)을 학습하면 이미지 어디서나 해당 패턴을 감지할 수 있습니다.
📚 3. 계층적 학습 (Hierarchical Features)
층이 깊어질수록 **단순한 엣지 → 복잡한 모양 → 고수준 부위/객체**로 추상화 수준이 높아집니다. 사람의 시각 피질이 사물을 인지하는 방식과 정확히 일치합니다.
🎯 4. 이동 불변성 (Translation Invariance)
합성곱 연산과 Pooling 축소를 거치면서 피사체(예: 고양이)가 이미지의 중앙, 좌측, 우측 등 **어느 위치로 이동하더라도 동일하게 인식**하는 강인성을 가집니다.
