Part 4. Deep Residual Learning Vision Backbone

ResNet-50 이미지 분류

잔차 학습(Residual Learning) 및 Skip Connection 아키텍처를 통해 심층 신경망의 기울기 소실 문제를 해결한 대표적 50계층 CNN 백본 모델과 CLIP 멀티모달 패러다임을 상세 비교한다.

1. ResNet-50 개념 & 잔차 학습 시각화

💡
ResNet-50 핵심 요약
층이 50층 이상으로 깊어질 때 발생하는 기울기 소실(Vanishing Gradient) 문제를 해결하기 위해 지름길(Skip Connection)을 도입하여 잔차 H(x) = F(x) + x를 학습하는 대표적 CNN 아키텍처이다.
❌ 기존 심층 CNN의 한계 (Degradation Problem)
신경망 층을 더 깊게 쌓을수록 기울기 소실/폭발 현상이 발생하여, 오버피팅이 아님에도 불구하고 50층 이상의 단순 CNN(Plain Net)이 20층 모델보다 에러율이 높아지는 성능 저하 문제 발생
✅ ResNet의 해결책 (Skip Connection / 잔차 학습)
입력 데이터를 뒤쪽 레이어로 100% 전달하는 지름길(Shortcut Connection)을 구축하여, 미세한 차이점(잔차 F(x))만 배우도록 유도하여 100층 이상의 초심층 모델 수렴 달성
🖼️
1. 특징 추출 관점에서의 '잔차(Residual)' 매핑 개념
🚀
2. ResNet-50 3-Stage 직렬 잔차 블록 (Serial Bottleneck Layers) 통합 파이프라인
💡
Bottleneck (병목) 아키텍처와 채널 압축 원리
ResNet-50의 잔차 블록은 연산량과 컴퓨터 메모리를 아끼기 위해 채널 축소 ➔ 특징 추출 ➔ 채널 확장 단계로 설계된 Bottleneck(병목) 구조를 채택했다.
  • 1×1 conv ➔ 채널 축소 역할: 3×3에서의 연산 비용을 절감하기 위해 입력 채널 수(예: 256)를 작은 규모(예: 64)로 압축
  • 3×3 conv ➔ 특징 추출 역할: 압축되어 가벼워진 소규모 채널 위에서만 공간적 이미지 특징을 효율적으로 연산
  • 1×1 conv ➔ 채널 확장 역할: 특징 추출이 완료된 데이터를 원래 신경망의 깊이(256 채널)로 다시 확장하여 복원
🏫 쉽게 배우는 비전 비유: 무거운 짐(256 채널)을 통째로 들고 연산 비용이 9배나 비싼 복잡한 관문(3×3 연산)을 통과하는 것보다, 일단 압축 팩(1×1 채널축소)으로 부피를 64로 줄여서 저렴하고 가볍게 통과한 뒤, 관문을 지나서 다시 본래 부피(1×1 채널확장)로 부풀리는 현명한 다이어트 연산 전략이다.

2. 3단계 작동 과정 & PyTorch 실행 코드

🔄 ResNet-50 핵심 작동 과정 3단계

1
계층적 특징 추출 (Feature Pyramid)
낮은 층에서는 점, 선, 질감 등 국소 특징을 다루고, 깊은 층으로 갈수록 사물의 고차원 시각 특징 계층적 추출
2
잔차 합산 (Residual Addition)
Bottleneck 블록 연산 결과 F(x)에 입력 x를 덧셈하여 기울기 전달 최단경로 최적화 보장
3
Global Avg Pooling & 분류
특징 맵 공간을 1×1로 축약(GAP)하여 파라미터를 대폭 줄인 뒤, FC 레이어를 통해 ImageNet 1,000개 클래스 확률 출력
💻
PyTorch & Transformers 기반 ResNet-50 추론 코드
Hugging Face transformers 라이브러리를 통해 사전학습된 ResNet-50 모델을 로드하고 이미지를 분류하는 소스 코드이다.

🔗 Hugging Face - microsoft/resnet-50 모델 페이지 바로가기 
from transformers import AutoImageProcessor, AutoModelForImageClassification
import torch
from PIL import Image

# 1. Hugging Face 허브에서 이미지 전처리기 및 ResNet-50 모델 로드
processor = AutoImageProcessor.from_pretrained("microsoft/resnet-50")
model = AutoModelForImageClassification.from_pretrained("microsoft/resnet-50").eval()

# 2. 이미지 로드 및 모델 전용 텐서 전처리 실행
image = Image.open("sample_fox.jpg")
inputs = processor(images=image, return_tensors="pt")

# 3. 모델 순전파 연산
with torch.no_grad():
    logits = model(**inputs).logits

# 4. Softmax 확률 계산 및 예측 레이블 매칭
probs = logits.softmax(dim=-1)
predicted_label = logits.argmax(-1).item()

# 5. 설정된 config로부터 사람이 읽을 수 있는 클래스 명칭 출력
category_name = model.config.id2label[predicted_label]
print(f"Top-1 예측 결과: {category_name} ({probs[0][predicted_label].item()*100:.2f}%)")

3. CLIP vs ResNet-50 모델 특성 상세 비교

⚔️
전통 지도학습(ResNet-50) vs 멀티모달(CLIP) 패러다임 비교
동일한 이미지(수채화 여우 그림)를 처리할 때 지도학습 기반 ResNet-50과 멀티모달 대조학습 기반 CLIP 모델의 주요 차이점이다.
비교 항목 ResNet-50 (전통 지도학습 CNN) CLIP (멀티모달 파운데이션 모델)
학습 방식 ImageNet 1,000개 클래스 단일 라벨 지도학습 4억 개 이미지-텍스트 대조학습 (Contrastive)
분류 방식 사전 정의된 1,000개 범주 정적 출력 임의 작성한 텍스트 임베딩과의 유사도 (Zero-Shot)
화풍/스타일 인식 불가 (객체 종류에만 국한) 가능 ("watercolor" 화풍 세부 구분)
Zero-shot 유연성 새 클래스 등장 시 수천 장 데이터 및 FC 재학습 필수 텍스트 레이블만 수정하면 코드/재학습 없이 구동
여우 수채화 예시 red fox (85.2%) a watercolor painting of a fox (92.4%)
🔍 ResNet-50의 핵심 시각 관점
객체의 시각적 국소 형태(주둥이, 귀, 털 색상 패턴)에 집중하여 사물 종류를 분류한다. 화풍(수채화/유화/사진) 정보는 클래스 정의에 없으므로 무시되거나 분류 노이즈로 작용한다.
🎨 CLIP의 핵심 시각 관점
이미지 전체의 의미적 맥락(Semantic Context)을 파악한다. 객체 명칭뿐만 아니라 화풍, 미술 스타일, 배경 분위기까지 텍스트 임베딩 차원에서 완벽 대조한다.
