1. SANA (Linear DiT) 모델 개요 & 추론 시뮬레이터

🚀
SANA (Linear DiT) 모델 개요
NVIDIA NVlabs에서 개발한 SANA는 기존 Stable Diffusion 및 표준 DiT 대비 초고속 추론과 1024×1024 고해상도 생성을 지원하는 1.6B 파라미터 경량 모델이다. 선형 어텐션(Linear Attention) 메커니즘을 적용하여 기존 2차원 공간 연산 복잡도 O(N2)를 O(N)으로 획기적으로 낮춰 빠른 생성을 지원한다.

🎨 SANA 텍스트-투-이미지 디노이징 시뮬레이터 (Diffusion Explainer)

텍스트 프롬프트 입력부터 Gemma-2B 인코더 및 Linear DiT 노이즈 제거 루프를 거쳐 최종 판다 서예 이미지가 완성되는 시각화 시뮬레이터이다. ▶ 버튼을 누르거나 타임스텝 슬라이더를 조절하여 디노이징 단계를 직관적으로 탐색할 수 있다.

🔗 Hugging Face - Sana_1600M_1024px_diffusers 공식 저장소 바로가기

💻 SANA 파이프라인 생성 핵심 코드

PyTorch 및 Diffusers를 이용한 모델 로드와 추론 코드 예시이다.
1. 파이프라인 및 가중치 로드
import torch
from diffusers import SanaPipeline

pipe = SanaPipeline.from_pretrained(
    "Efficient-Large-Model/Sana_1600M_1024px_diffusers",
    variant="fp16",
    torch_dtype=torch.float16,
)
pipe.to("cuda")
pipe.vae.to(torch.bfloat16)
pipe.text_encoder.to(torch.bfloat16)
2. 텍스트 기반 이미지 생성 및 저장
image = pipe(
    prompt='A cute 🐼 eating 🎋, ink drawing style',
    height=1024,
    width=1024,
    guidance_scale=4.5,
    num_inference_steps=20,
)[0]
image[0].save("sana.png")

📊 하이퍼파라미터 튜닝 가이드

디퓨전 기반 이미지 생성 시 조정하는 핵심 매개변수 설정 효과 요약이다.
매개변수 설정 범주 상세 효과 및 비고
guidance_scale 1.0~3.0 (낮음)
4.0~7.5 (골든존)
8.0~15.0 (과대비) 		프롬프트 준수 강도. 과도할 경우 색상 과포화 발생
num_inference_steps 1~10 (초안)
18~30 (추천 품질)
45~60 (비효율) 		노이즈 제거 단계 수. 20스텝 근처에서 최적 품질 형성
