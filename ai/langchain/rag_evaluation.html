RAG 시스템 평가 가이드 Ragas 프레임워크 기반 핵심 4대 지표 분석 및 인터랙티브 평가 시뮬레이터

RAG(Retrieval-Augmented Generation) 시스템을 구축하고 나면 가장 먼저 마주하는 난제는 "이 답변이 정말로 정확하고 안전한가?"에 대한 주관적 평가 한계이다. Ragas(Retrieval Augmented Generation Assessment) 프레임워크를 활용해 LLM을 자동 평가 판정관으로 도입하는 정량적 지표 체계를 다룬다.

"RAG 시스템을 객관적으로 정량 평가하기 위한 4대 핵심 축(Ragas Quad) 지표와 파이썬 구현 및 인터랙티브 계산 시뮬레이터를 제공한다."

1. RAG 평가의 4대 핵심 축 (Ragas Quad)

실제 정답(Ground Truth)을 포함한 4대 핵심 구성요소 간의 수평적 구조 및 유기적 검증 관계망이다.

CONTEXT PRECISION

1. 맥락 정밀도 (Context Precision)

사용자 질문에 도움이 되는 필수 문서 조각(Chunk)이 검색 결과 상위에 조밀하게 위치하는지 평가함

💡 쉽게 말해: "가져온 문서들 중 쓸모있는 중요 지식이 맨 위에 잘 정렬되어 있는가?"
CONTEXT RECALL

2. 맥락 재현율 (Context Recall)

실제 정답(Ground Truth)을 만들기 위해 필요한 지식 성분이 검색된 맥락 문서에 빠짐없이 커버되었는지 검증함

💡 쉽게 말해: "정답을 맞히는 데 꼭 필요한 필수 지식을 빠뜨리지 않고 다 가져왔는가?"
FAITHFULNESS

3. 충실성 / 진실성 (Faithfulness)

생성된 답변이 검색된 맥락 문서에만 철저히 근거했는지, AI가 지어낸 거짓말(환각/Hallucination)이 없는지 진단함

💡 쉽게 말해: "AI 답변이 가져온 문서에만 바탕을 두고 있는가? (지어낸 환각 유무)"
ANSWER RELEVANCE

4. 답변 관련성 (Answer Relevance)

생성된 답변이 사용자 질문의 핵심 의도에서 벗어나거나 딴소리를 하지 않고 정확히 부합하는지 평가함

💡 쉽게 말해: "AI 대답이 질문자의 의도에 꼭 맞게 답하고 있는가? (초점 이탈 유무)"

2. 실전 Ragas 평가 파이프라인 (eval_ragas.py 흐름도)

실무 프로젝트(chatbot-project/servers/eval_ragas.py)에서 인프라 초기화부터 LLM 테스트셋 합성, RAG 실행 데이터 수집, 4대 지표 심사 및 MD 리포트 누적 기록까지의 전체 오토메이션 파이프라인 구조도이다.

💻 실전 파이프라인 코드 (chatbot-project/servers/eval_ragas.py)

# chatbot-project/servers/eval_ragas.py 핵심 파이프라인 예시

import os
from pathlib import Path
import json
import pandas as pd
from ragas import EvaluationDataset, evaluate
from ragas.metrics import Faithfulness, AnswerRelevancy, LLMContextRecall, ContextPrecision
import main

# 1. RAG 에이전트 인프라 초기화 및 문서 적재
main.init_vectorstore()
main.rag_workflow = main.build_rag_graph()

# 2. 테스트 케이스 준비 (캐시 파일 또는 LLM 자동 생성)
test_cases_file = Path("./test_cases.json")
if test_cases_file.exists():
    with open(test_cases_file, "r", encoding="utf-8") as f:
        test_cases = json.load(f)

# 3. RAG 워크플로우 대조 실행 및 데이터 수집
eval_data = []
for case in test_cases:
    initial_state = {"question": case["question"], "use_rag": True}
    final_state = main.rag_workflow.invoke(initial_state)
    
    eval_data.append({
        "user_input": case["question"],
        "response": final_state["answer"],
        "retrieved_contexts": [final_state["context"]] if final_state["context"] else [],
        "reference": case["ground_truth"]
    })

# 4. Ragas 4대 지표 심사 구동
dataset = EvaluationDataset.from_list(eval_data)
metrics = [
    Faithfulness(llm=main.llm),
    AnswerRelevancy(llm=main.llm),
    LLMContextRecall(llm=main.llm),
    ContextPrecision(llm=main.llm)
]
results = evaluate(dataset=dataset, metrics=metrics, llm=main.llm, embeddings=main.embeddings)

# 5. 상세 결과 CSV 및 MD 파일 누적 기록 (ragas_eval_history.md)
df_results = results.to_pandas()
df_results.to_csv("ragas_eval_results.csv", index=False, encoding="utf-8-sig")

avg_f = df_results["faithfulness"].mean()
avg_r = df_results["answer_relevancy"].mean()
print(f"평균 점수 - Faithfulness: {avg_f:.4f}, Relevancy: {avg_r:.4f}")

3. 지표별 진단 및 RAG 성능 개선 솔루션

평가 엔진에서 특정 지표 저하 감지 시 조치해야 할 프롬프트 및 인프라 개선 방안이다.

지표 상태 (평가 항목) 문제 원인 (현재 상태) 개선 조치 방안 (쉽게 풀이한 용어 설명)
Context Precision 저하
(맥락 정밀도 부족)		 엉뚱한 문서가 섞이거나
중요 문서가 뒤로 밀림		 · 재정렬 모델 (Reranker) 도입: 검색된 문서 조각 중 연관성이 가장 높은 중요 문서를 최상단으로 다시 순위 배치함
· 검색 개수 (Top-K) & 질문 확장 (Query Expansion): 한 번에 가져오는 참고 문서 수를 조정하고 검색 키워드를 보완함
Context Recall 저하
(맥락 재현율 부족)		 정답에 필요한 핵심 지식이
검색에서 누락됨 (정보 부재)		 · 임베딩 모델 고도화: 단어의 의미적 유사도를 정확히 판별하는 최신 임베딩 모델로 교체함
· 문서 조각 (Chunk) 분할 조정 & 혼합 검색 (BM25 Hybrid): 단어 일치 검색과 의미 검색을 결합하여 지식 누락을 방지함
Faithfulness 저하
(충실성/진실성 부족)		 가져온 문서에 없는 내용을
AI가 지어냄 (환각 발생)		 · 시스템 프롬프트 (System Prompt) 제약 강화: "반드시 제공된 문서 내용만을 바탕으로 답변하라"는 지시를 강제함
· AI 무작위성 (Temperature = 0) 조절: AI의 엉뚱한 상상력을 0으로 끄고 가져온 문서 내용을 있는 그대로 요약하도록 제한함
Answer Relevance 저하
(답변 관련성 부족)		 질문자의 의도와 딴판인
엉뚱한 대답을 함 (초점 이탈)		 · 출력 포맷 강제 정의: 질문자가 원하는 명확한 답변 구조(목록형, 요약형 등)를 프롬프트에 고정함
· 질문 재작성 (Query Rewriting): 애매한 사용자 질문을 AI가 정확히 이해할 수 있는 명확한 표현의 문장으로 재구성함

4. 강의 핵심 요약

  • Ragas Quad: Question, Ground Truth, Context, Answer 4대 요소 간 정량적 관계 검증
  • 검색 성능 지표: Context Precision(상위 정렬도), Context Recall(정보 커버리지)
  • 생성 성능 지표: Faithfulness(맥락 근거 진실성), Answer Relevance(질문 의도 부합성)
  • 성능 개선: 리랭커, 하이브리드 검색, Temp 0 세팅, 쿼리 재작성 기법으로 단계별 보정
