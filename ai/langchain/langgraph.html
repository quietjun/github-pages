💡 WHAT IS LANGGRAPH?

LangGraph는 LangChain 생태계의 고성능 에이전트 프레임워크로, 기존 단방향 파이프라인(LCEL)의 유턴 불가능한 흐름을 혁신하여 순환 루프(Cycle)와 복잡한 분기 조건을 자유롭게 설계할 수 있도록 지원한다. LLM의 오답을 스스로 재조회 및 수정하는 자율 보정형 RAG 에이전트와 사람의 최종 승인이 유기적으로 결합된 상용 워크플로우를 완벽한 상태(State) 기반 데이터 흐름으로 안정성 있게 통제할 수 있다.

01 핵심 구성요소
📋

State

공유 메모장 · 공용 게시판
  • 모든 노드가 공유하는 데이터 저장소
  • 이전 작업 기록 → 에러 복구 가능
  • 중간 결과 누적 → 최종 판단 근거
⚙️

Node

전문가 팀원 · 담당자
  • 특정 업무만 수행하는 단위 함수
  • State 입력 → 처리 → State 업데이트
  • 검색 / 요약 / 번역 / 평가 등 분리
  • Python 함수 또는 LLM 호출 단위
🔀

Edge

업무 지시서 · 통로
  • 노드 간 연결 경로 정의
  • 일반 엣지: 항상 동일 경로 이동
  • 조건부 엣지: 상태에 따라 동적 분기
  • 품질 낮음 → 재검색 / 완료 → END

04 LCEL vs LangGraph

LCEL · 기존 방식

일방통행 레시피
→ 순서대로만 실행, 되돌아가기 불가

직선 구조 / 유턴 불가 단순 파이프라인에 최적 조건 분기·반복 처리 어려움

LangGraph · 새로운 방식

사거리·회전교차로가 있는 도로망
→ 조건 분기, 루프, 유턴 모두 가능

사이클(Cycle) 구조 지원 조건부 엣지로 동적 분기 복잡한 에이전트 로직 구현 가능
05 언제 무엇을 써야 할까?

LCEL 선택 시

  • 단순 번역 / 요약 등 1회성 작업
  • 입출력이 명확한 선형 파이프라인
  • 빠른 프로토타이핑 필요 시
  • 분기·반복 없는 단순 체인

LangGraph 선택 시

  • 논문 수십 편 읽고 비판적 분석 보고서
  • 코드 작성 → 에러 수정 → 재실행 루프
  • 다단계 검증이 필요한 RAG 파이프라인
  • 사람 승인이 필요한 자동화 에이전트
🤖

요약: LangGraph = LLM을 진짜 '에이전트'로 격상시키는 도구

단순 챗봇 구조를 탈피하여, 스스로 상태를 판단하고 행동하는 자율 에이전트 구조를 실현한다.

06 Python LangGraph 실무 구현 예제

실습 노트북의 Step 7에서 구성된 RAGState 기반의 2노드(Retrieve ➡️ Generate) 순차 에이전트 파이프라인의 실제 Python 구현 코드입니다. 

# 1. State 타입 정의 (공유 메모리)
from typing import TypedDict

class RAGState(TypedDict):
    question: str
    context: str
    answer: str

# 2. Retrieve 노드 정의 (유사 문서 검색)
def retrieve(state: RAGState) -> RAGState:
    question = state["question"]
    
    # 청킹된 Vector Store에서 문장 검색 후 포맷팅
    docs = retriever_chunked.invoke(question)
    context = "\n\n".join([doc.page_content for doc in docs])
    return {"context": context}

# 3. Generate 노드 정의 (답변 생성)
def generate(state: RAGState) -> RAGState:
    question = state["question"]
    context = state["context"]
    
    rag_prompt = ChatPromptTemplate.from_messages([
        ("system", "당신은 Yes24 상담원입니다. 검색된 자료에만 기반하여 답하세요:\n\n{context}"),
        ("human", "{question}")
    ])
    
    messages = rag_prompt.format_messages(context=context, question=question)
    response = llm.invoke(messages)
    return {"answer": response.content}

# 4. StateGraph 워크플로우 구성 및 컴파일
from langgraph.graph import StateGraph, START, END

workflow = StateGraph(RAGState)

# 노드 추가
workflow.add_node("retrieve", retrieve)
workflow.add_node("generate", generate)

# 엣지 연결 (순차 실행 구조)
workflow.add_edge(START, "retrieve")
workflow.add_edge("retrieve", "generate")
workflow.add_edge("generate", END)

# 그래프 컴파일 및 호출
rag_graph = workflow.compile()
result = rag_graph.invoke({"question": "Yes24에서 총알배송이 뭔가요?"})
print(result["answer"])
