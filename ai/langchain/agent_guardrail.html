01

Trustworthiness (신뢰성 및 가드레일) 아키텍처

자율성이 부여된 AI 에이전트는 예기치 못한 도구 호출 및 오동작을 일으킬 수 있다. 따라서 실무에 상용 에이전트를 안전하게 배포하기 위해서는 보안 정책 강제 검증 및 입출력 단계별 다중 필터 차단 가드레일 설계가 필수적이다.

🛡️ 안전하고 신뢰할 수 있는 에이전트 파이프라인 설계

에이전트 보호 레이어 흐름도
사용자 입력 ➡️ 입력 가드레일 ➡️ Agent / ReAct ➡️ 도구 실행 전 검증 ➡️ 출력 가드레일 ➡️ 최종 출력
보호 계층주요 역할 및 작동 방식검증 예시
입력 가드레일 에이전트 실행 전, 위험하거나 부적절한 사용자 입력을 선제 차단함. "시스템 해킹", "비밀번호 탈취" 시도 차단
도구 실행 전 검증 도구(API) 실행 직전, 비즈니스 요건 및 정책 준수 여부를 강제 검증함. 발급 금액 정책 한도(최대 2만원) 체크, 주문번호 존재 유무 확인
출력 가드레일 응답 반환 직전, 개인정보 및 민감 데이터의 외부 유출을 필터링함. 주민등록번호, 계좌번호, 상세 주소 정보 마스킹
