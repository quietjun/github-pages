pandas Broadcasting 완벽 이해
핵심: 다른 크기 배열 연산
→ 작은 것을 큰 것에 맞춰 자동 확장
→ 규칙 따르면 호환 : 연산 가능
→ 규칙 어기면 에러 : shape 불일치
Broadcasting 규칙 3가지

규칙 1: 차원 개수 맞추기

차원 적은 쪽의 앞에 1 추가

step 1) 차원 개수 확인 A: (3, 4) → 2차원 ✓ B: (4,) → 1차원 (모자람) step 2) B의 앞에 1 추가 (4,) → (1, 4) step 3) 비교 A: (3, 4) vs B: (1, 4) → 차원 같음 ✓

규칙 2: 각 차원 크기 호환성

각 축의 크기: 같거나 / 하나가 1 / 없는 축

A shape: (3, 4) vs B shape: (1, 4) 축0 비교: 3 vs 1 → 1이 작으니 3에 맞춰 확장 ✓ 축1 비교: 4 vs 4 → 크기 같음 ✓ 결론: 호환 가능 ✓

규칙 3: 크기 1인 축은 확장

값을 반복해서 채워 큰 크기에 맞춤

원본 B: (1, 4) [[5, 6, 7, 8]] 확장 과정: 축0의 크기를 1 → 3으로 변경 [[5, 6, 7, 8], [5, 6, 7, 8], [5, 6, 7, 8]] 최종: (3, 4) 모든 행이 동일한 값으로 채워짐
시각적 예제
호환 vs 비호환

✓ 호환 가능

(3, 4) + (4,)

→ (1, 4)로 변환 후 호환

(5, 1) + (3,)

→ (1, 3)로 변환 후 호환

(1, 1, 3) + (2, 1)

→ (1, 1, 3) + (1, 2, 1)

✗ 비호환

(3, 4) + (3,)

축 불일치: 4 vs 3

(2, 3) + (2, 4)

축1 크기 다름: 3 vs 4

(3,) + (4,)

1D 크기 다름: 3 vs 4

실무 패턴

패턴 1: 정규화 (각 행에서 평균 빼기)

데이터: df shape (100, 4) 평균값: df.mean() shape (4,) 연산: df - df.mean() → (4,)는 자동으로 (1, 4)로 변환 → (100, 4) - (1, 4) : 호환 ✓ 결과: 각 행에서 열별 평균 제거됨

패턴 2: 스칼라 연산

배열: arr shape (50, 3) 스칼라: 10 (shape ()) 연산: arr * 10 → scalar는 모든 크기와 호환 → 모든 원소에 10 곱하기 ✓ 결과: (50, 3) 유지

패턴 3: reshape로 명시 (안전 방법)

원본: mean_vals shape (4,) 명시적 변환: mean_vals.reshape(1, -1) → (4,) → (1, 4) 명확하게 표현 장점: broadcasting 규칙 직관적 실수로 인한 에러 가능성 낮음
💡 기억 법칙

뒤에서부터 비교 (오른쪽 축부터)

A: (3, 4, 5) vs B: (4, 5)

→ 뒤부터: 5=5 ✓
→ 그 다음: 4=4 ✓
→ 남은 것: 3과 없는 축 ✓

→ 호환 가능

1인 축은 언제든 확장

크기 1인 축만 자동 반복 가능

(1, 4) → (3, 4) : 가능
(2, 4) → (3, 4) : 불가능
