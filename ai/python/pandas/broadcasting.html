pandas Broadcasting 완벽 이해
핵심: 다른 크기 배열끼리 연산할 때,
데이터를 자동으로 늘려서(Stretching) 크기를 맞추는 마법 같은 원리입니다.
Broadcasting 3단계 작동 원리

규칙 1: 낮은 차원 앞에 '1' 채우기 (Prepend 1s)

두 배열의 차원 개수가 다르면, 차원이 낮은 쪽의 왼쪽(앞)에 1을 추가하여 차원 개수를 맞춥니다.

A: (3, 4) # 2차원 B: (4,) # 1차원 → (1, 4)로 간주

규칙 2: 크기가 1인 축 늘리기 (Stretching)

차원 내에서 크기가 1인 축은, 상대방의 크기에 맞춰 값을 반복해서 채웁니다.

B: (1, 4) → [[5, 6, 7, 8]] 확장: (3, 4) → [[5, 6, 7, 8], [5, 6, 7, 8], [5, 6, 7, 8]]

규칙 3: 호환성 최종 확인 (Compatibility Check)

뒤에서부터 축별로 비교했을 때, [크기가 같음] 또는 [둘 중 하나가 1임]을 만족해야 합니다.

호환 조건: 1) 두 축의 크기가 정확히 같을 때 2) 한쪽 축의 크기가 1일 때 (늘릴 수 있음) 3) 한쪽 축이 존재하지 않을 때 (1을 채우면 되므로)
시각적 예제
호환 vs 비호환 한눈에 보기

✓ 연산 가능 (호환)

(3, 4) + (4,) → (1, 4)로 변환

(5, 1) + (3,) → (5, 3)으로 확장

(10, 1) + (10, 1) → (10, 1)

✗ 연산 불가 (에러)

(3, 4) + (3,) → (1, 3)은 축1(4 vs 3) 불일치

(2, 3) + (2, 4) → 축1 크기 다름

(3,) + (4,) → 원소 개수 다름

💡 실무 팁: 뒤에서부터 비교하세요

Broadcasting 가능 여부를 빨리 알려면 오른쪽(마지막 축)부터 숫자를 맞추어보세요. 숫자가 같거나, 한쪽이 1이면 통과입니다!
