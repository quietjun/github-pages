pandas axis 핵심 이해
핵심: axis = 이동 방향
→ axis=0: 위 → 아래 (↓) : 각 열 순회
→ axis=1: 좌 → 우 (→) : 각 행 순회
축 선택:
index A B C
row_0 10 20 30
row_1 40 50 60
row_2 70 80 90
axis=0 설명

axis=0 (행 방향 ↓)

방향: 위 → 아래

순회: 각 열(column)

결과: 열 개수 = 반환값 개수

df.sum(axis=0)
→ A:120, B:150, C:180

axis=1 (열 방향 →)

방향: 왼 → 오른

순회: 각 행(row)

결과: 행 개수 = 반환값 개수

df.sum(axis=1)
→ row_0:60, row_1:150, row_2:240

💡 영구기억 법칙

방법 1: 이름으로 기억

• 0 = "영(0)행" = 행 : ↓ 이동
• 1 = "일(1)열" = 열 : → 이동

방법 2: 변화로 기억

• axis=0 → 행 변함 (열 연산)
• axis=1 → 열 변함 (행 연산)
