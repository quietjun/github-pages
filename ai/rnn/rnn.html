RNN & Seq2Seq 시각화 및 메커니즘

순환 신경망(Recurrent Neural Network)의 기본 셀 연산 구조와 시퀀스-투-시퀀스(Seq2Seq) 모델의 인코더-디코더 동작 원리를 시각적으로 학습한다.

1. 기존 신경망의 한계와 RNN의 필요성

기존 신경망(Feedforward/MLP)의 한계
1. 가변 길이(Variable Length) 입력의 한계

문장, 음성, 주가 등 연속 데이터는 시점마다 길이가 매번 가변적이지만, 기존 MLP는 입력 노드 수(Vector Dimension)가 고정(Fixed Size)되어 있어 다양한 길이의 시퀀스를 유연하게 수용하지 못합니다.

2. 순서 및 시간적 맥락(Context) 정보의 상실

기존 신경망은 모든 입력 데이터를 독립적인 개체(Independent)로 취급하여 이전 타임스텝의 결과나 단어의 등장 순서를 기억하고 다음 연산에 전달하지 못합니다.

🏃‍♂️ RNN의 해결책: 릴레이 바통 터치 (순환 구조)

이러한 단절 문제를 해결하기 위해, RNN은 이전 단어를 처리할 때 만들어진 은닉 상태(Hidden State, h)를 다음 단어 처리 장치로 릴레이 바통처럼 끊임없이 넘겨주며 문맥과 기억을 보존합니다.

은닉 상태 (ht)의 역할

과거 시점(t = 1부터 t-1까지) 축적된 문맥 정보를 고정 크기 벡터로 압축 보유함

가중치 공유 (Weight Sharing)

모든 타임스텝에서 동일한 가중치 행렬 (Whh, Wxh, Why)을 재사용하여 시퀀스 길이에 유연함

2. RNN 셀 언롤링 (Unrolling)

재귀적 루프 구조의 단일 RNN 셀을 시점(t-1, t, t+1)에 따라 시간축으로 펼쳐 표현(Unroll)하면 순전파 및 역전파 흐름이 명확히 가시화된다.

장기 의존성 한계 (Long-term Dependency Problem)

언롤링 구조에서 시퀀스가 길어지면 앞단의 은닉 상태 기억이 여러 셀을 거치며 점차 희석·소실되는 근본적 한계가 존재합니다.

3. PyTorch nn.RNN vs nn.RNNCell 비교

PyTorch 프레임워크는 전체 시퀀스를 일괄 처리하는 nn.RNN 모듈과, 타임스텝별로 직접 루프를 제어하는 nn.RNNCell 모듈 두 가지 방식을 제공한다.

nn.RNN (전체 시퀀스 일괄 처리)

입력 시퀀스 전체 텐서를 한 번에 입력받아 내부 루프를 자동 순회하여 최종 출력과 상태를 반환함.

nn.RNNCell (타임스텝별 단일 셀)

단일 타임스텝(xt)의 텐서만 입력받아 한 단계의 은닉 상태(ht)만 계산하므로 커스텀 루프에 유리함.

nn.RNN vs nn.RNNCell 파라미터 및 텐서 형상 비교표

구분 nn.RNN (Multi-step) nn.RNNCell (Single-step) 비고
입력 텐서 형상 (Input Shape) (seq_len, batch, input_size) (batch, input_size) nn.RNN은 seq_len 차원 포함
은닉 상태 형상 (Hidden Shape) (num_layers * num_directions, batch, hidden_size) (batch, hidden_size) RNNCell은 단일 레이어 배치 형상
출력 텐서 형상 (Output Shape) (seq_len, batch, num_directions * hidden_size) (batch, hidden_size) RNNCell의 출력은 다음 ht와 동일
주요 사용 목적 기존 표준 시퀀스 모델링 (Fast Batch) Seq2Seq 디코더, 커스텀 어텐션 루프 구현 자유도: RNNCell > nn.RNN

PyTorch 구현 비교 코드

import torch
import torch.nn as nn

# 1. nn.RNN 사용 예시 (전체 시퀀스 일괄 연산)
rnn = nn.RNN(input_size=10, hidden_size=20, num_layers=1, batch_first=True)
inputs = torch.randn(5, 3, 10) # (batch=5, seq_len=3, input_size=10)
out, h_n = rnn(inputs)
print("nn.RNN Output Shape:", out.shape) # torch.Size([5, 3, 20])

# 2. nn.RNNCell 사용 예시 (타임스텝 루프 수동 직접 제어)
rnn_cell = nn.RNNCell(input_size=10, hidden_size=20)
hx = torch.zeros(5, 20) # 초기 은닉 상태 (batch=5, hidden_size=20)
outputs = []
for t in range(inputs.size(1)):
    hx = rnn_cell(inputs[:, t, :], hx) # 타임스텝별 갱신
    outputs.append(hx)
out_cell = torch.stack(outputs, dim=1)
print("nn.RNNCell Output Shape:", out_cell.shape) # torch.Size([5, 3, 20])

4. Seq2Seq 인코더-디코더 & 시뮬레이션

시퀀스-투-시퀀스(Seq2Seq)는 입력 시퀀스를 압축하는 Encoder와, 전달받은 Context Vector 기반으로 타겟 시퀀스를 생성하는 Decoder 구조로 이루어진다.

Encoder
인코더 (압축 메커니즘)

입력 문장의 토큰들을 차례대로 읽어 최종 은닉 상태인 Context Vector에 문맥을 응축함

Decoder
디코더 (생성 메커니즘)

Context Vector를 초기 상태로 받아 <SOS> 토큰부터 시작하여 <EOS> 토큰까지 타겟 언어 번역을 생성함

💡 핵심 수식 및 활성화 함수 해설
📐 tanh (하이퍼볼릭 탄젠트)
ht = tanh(Wx·xt + Wh·ht-1 + b)

새로운 은닉 상태의 모든 값 범위를 -1에서 1 사이로 스케일링하여 수치 폭발이나 소실을 방지함

🗜️ 컨텍스트 벡터 (Context Vector)
c = henc_last

인코더의 마지막 은닉 상태로, 전체 문장의 문맥 의미가 고밀도로 축약되어 디코더의 최초 기억으로 제공됨

📊 softmax (소프트맥스)
yt = softmax(Wy·st + b)

디코더 셀의 실수 수치 벡터를 어휘 사전 단어별 확률 분포(합 1.0)로 정규화하여 최선의 단어를 선택함

5. 강의 핵심 요약

  • RNN 은닉 상태 (ht): 이전 타임스텝의 은닉 상태와 현재 입력을 결합하여 문맥 정보를 갱신 및 유지한다.
  • nn.RNN vs nn.RNNCell: nn.RNN은 전체 시퀀스 자동 배치 처리, nn.RNNCell은 타임스텝별 개별 루프 수동 연산용 모듈이다.
  • Seq2Seq 구조: 입력 시퀀스 전체를 고정 길이의 Context Vector로 압축하는 Encoder와, 이를 받아 새로운 시퀀스를 차례대로 생성하는 Decoder로 구성된다.
