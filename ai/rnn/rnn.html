RNN & Seq2Seq 시각화 및 메커니즘

순환 신경망(Recurrent Neural Network)의 기본 셀 연산 구조와 시퀀스-투-시퀀스(Seq2Seq) 모델의 인코더-디코더 동작 원리를 시각적으로 학습한다.

1. 기존 신경망의 한계와 RNN의 필요성

기존 신경망(MLP)의 한계
1. 가변 길이 입력 수용 불가

문장, 주가 등 연속 데이터는 시점마다 길이가 가변적이지만, MLP는 입력 노드 수(Vector Dimension)가 고정되어 유연한 처리가 불가능합니다.

2. 시간적 맥락(Context) 정보 상실

모든 입력 데이터를 독립 객체(Independent)로 취급하여 이전 타임스텝의 정보나 단어 순서를 기억하지 못합니다.

RNN의 해결책: 릴레이 바통 터치

이전 타임스텝의 은닉 상태(Hidden State, h)를 바통처럼 넘겨 문맥을 보존하고, 동일한 가중치(W_xh, W_hh)를 공유하여 가변 시퀀스를 처리합니다.

2. RNN 셀 언롤링 (Unrolling)

재귀적 루프 구조의 단일 RNN 셀을 시점(t-1, t, t+1)에 따라 시간축으로 펼쳐 표현(Unroll)하면 순전파 및 역전파 흐름이 명확히 가시화된다.

장기 의존성 한계 (Long-term Dependency Problem)

언롤링 구조에서 시퀀스가 길어지면 앞단의 은닉 상태 기억이 여러 셀을 거치며 점차 희석·소실되는 근본적 한계가 존재합니다.

3. PyTorch nn.RNN 파라미터 및 사용법

PyTorch 프레임워크에서 순환 신경망을 생성할 때 사용하는 nn.RNN 클래스의 생성자 시그니처와 핵심 파라미터의 역할을 학습한다.

# PyTorch nn.RNN 생성자 시그니처 (Constructor Signature)
nn.RNN(input_size, hidden_size, num_layers=1, bidirectional=False, batch_first=False)
input_size 필수 (Required)

입력 벡터 1개의 차원 수입니다. (예: 임베딩 차원이 768 ➔ input_size=768)

hidden_size 필수 (Required)

은닉 상태(Hidden State, h) 벡터의 차원 수입니다. (크기가 클수록 문맥 기억 용량 ↑)

num_layers 기본값 = 1

RNN 셀의 수직 적층 수(Stacked Layers)입니다. (수직 고차원 패턴 추상화)

bidirectional 기본값 = False

True 설정 시 순방향(→) 및 역방향(←) 동시 읽기 (은닉 크기: hidden_size × 2)

4. Seq2Seq (Sequence to Sequence) 인코더-디코더 & 대화형 시뮬레이터

시퀀스-투-시퀀스(Seq2Seq)는 입력 시퀀스를 압축하는 Encoder와, 전달받은 Context Vector 기반으로 타겟 시퀀스를 생성하는 Decoder 구조로 이루어진다.

💡 핵심 수식 및 활성화 함수 해설
📐 tanh (하이퍼볼릭 탄젠트)
ht = tanh(Wx·xt + Wh·ht-1 + b)

새로운 은닉 상태의 모든 값 범위를 -1에서 1 사이로 스케일링하여 수치 폭발이나 소실을 방지함

🗜️ 컨텍스트 벡터 (Context Vector)
c = henc_last

인코더의 마지막 은닉 상태로, 전체 문장의 문맥 의미가 고밀도로 축약되어 디코더의 최초 기억으로 제공됨

📊 softmax (소프트맥스)
yt = softmax(Wy·st + b)

최종 은닉 상태를 받아 각 단어별 확률 값(0~1 사이, 합=1)으로 변환하여 가장 높은 확률의 단어를 출력함

5. 강의 핵심 요약

  • RNN 은닉 상태 (ht): 이전 타임스텝의 은닉 상태와 현재 입력을 결합하여 문맥 정보를 갱신 및 유지한다.
  • nn.RNN 핵심 파라미터: input_size, hidden_size, num_layers, bidirectional 4가지 핵심 생성자 파라미터로 네트워크 구조를 설정한다.
  • Seq2Seq 구조: 입력 시퀀스 전체를 고정 길이의 Context Vector로 압축하는 Encoder와, 이를 받아 새로운 시퀀스를 차례대로 생성하는 Decoder로 구성된다.
