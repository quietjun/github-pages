🔄 LSTM (Long Short-Term Memory)

기본 RNN의 기울기 소실(Vanishing Gradient) 문제와 장기 의존성 한계를 극복하기 위해 설계된 LSTM의 핵심 메커니즘과 게이트별 작동 흐름을 학습한다.

1. 기본 RNN의 한계와 LSTM의 등장

시퀀스 길이가 길어질 때 기본 RNN은 과거 문맥 정보를 소실하지만, LSTM은 셀 상태(Cell State) 고속도로를 통해 장거리 문맥을 손실 없이 전달한다.

2. LSTM 셀 구조 및 게이트별 동작 시뮬레이션

LSTM 내부 셀은 장기 기억(Cell State, C)과 단기 기억(Hidden State, H)의 두 가지 경로로 구성되며, 3개의 게이트가 정보 흐름을 단계별로 제어한다.

Cell State (장기 기억)
Forget Gate (망각)
Input Gate (입력)
Candidate (기억 후보)
Output Gate (출력)
Candidate (기억 후보값) 개념 정리:
  • Candidate (˜Ct): 활성화 함수 tanh를 거쳐 생성된 현재 토큰 기반의 "새로운 기억 후보" (범위: -1 ~ +1)
  • 후보 단독으로 Cell State에 추가되지 않으며, 반드시 Input Gate (0 ~ 1)의 반영 비율과 곱해진 후 장기 기억 통로에 반영된다.
게이트 / 구획 개념 연산식 (Conceptual Formula) 주요 역할 및 의미 출력 범위
Forget Gate (망각) Sigmoid(이전 단기기억 h_t-1 + 현재 토큰 x_t) 이전 장기기억(Ct-1) 중 보존할 비율 결정 (0: 완전삭제 ~ 1: 완전보존) 0 ~ 1
Input Gate (입력) Sigmoid(이전 단기기억 h_t-1 + 현재 토큰 x_t) 새로 추출된 기억 후보 중 반영할 비율 결정 (0: 완전무시 ~ 1: 완전반영) 0 ~ 1
Candidate (기억 후보) tanh(이전 단기기억 h_t-1 + 현재 토큰 x_t) 현재 토큰 기반의 새로운 기억 후보 생성 (-1 ~ +1) -1 ~ +1
Cell State (장기 갱신) [이전 장기기억 × 보존 비율] + [새 기억 × 반영 비율] 기존 기억 삭제 + 새 기억 덧셈 ➔ 장기기억(Ct) 갱신 (기울기 소실 없음) 연속 수치
Output Gate (출력) Sigmoid(입력) × tanh(장기기억 C_t) 장기 기억 중 현재 필요한 정보만 추출하여 단기기억(ht) 출력 -1 ~ +1

3. 강의 핵심 요약

LSTM 구조의 핵심 요약 노트
  • Cell State (장기 기억 통로)는 덧셈(+) 연산 기반의 고속도로 구조로 구성되어, 긴 시퀀스 역전파 시에도 기울기 소실(Vanishing Gradient)이 발생하지 않는다.
  • Forget Gate는 삭제할 정보(0~1)를, Input Gate는 반영할 새 정보 비율(0~1)을 결정하여 Cell State를 갱신한다.
  • Output Gate는 갱신된 장기 기억 중 현재 시점에 필요한 정보만을 추출하여 Hidden State (단기 기억)로 최종 출력한다.
