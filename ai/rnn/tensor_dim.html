💡 텐서 차원(Shape) 변환 원리와 축(dim)의 실무적 이해

1. NLP 3차원 텐서 규격과 개요

자연어 처리 차원 전제

일반적으로 자연어 처리 분야의 딥러닝 모델에서는 문장 데이터를 임베딩하여 주입할 때, 무조건 3차원 텐서 규격 [Batch, Seq, Feature] (단어장 점수의 경우 [Batch, Seq, Vocab])으로 입력을 처리하도록 규격화되어 있다.

💡 핵심 용어 정의
• Batch (배치 크기 N) :
동시에 처리할 문장 개수 (예: 32)
• Seq (시퀀스 길이 L) :
문장 내 단어(토큰) 개수 (예: 10)
• Vocab (단어장 크기 V) : 어휘 사전 속 총 단어 개수 (예: 30,000)
3차원 텐서 [Batch, Seq, Vocab] 축(dim) 방향 시각화
실무 연산 포인트: 실제 모델 내부 연산 과정에서는 이 규격을 고정하지 않고 필요에 따라 차원을 인위적으로 줄이거나(Squeeze) 늘리는(Unsqueeze) 형상 변환을 지속적으로 수행한다.

2. 텐서 차원 조작의 2가지 핵심 목적

목적 1
최종 결과 도출 & 가중치 학습 (차원 줄이기)

수학적/비즈니스적 필요에 의해 텐서 차원을 인위적으로 줄여서(Squeeze / Argmax / Mean) 최종 결과나 학습 지표를 추출한다.

① 최종 번역 단어 1개 출력
[1, 1, 30000] (3차원 출력) ➔ squeeze ➔ [30000] (1차원 점수판) ➔ argmax ➔ 단어 ID '15' (0차원 스칼라)
② 균형 잡힌 가중치 학습 (Loss 통합)
[32] (32개 문장 오차 1차원) ➔ mean(dim=0) ➔ 단일 오차 Loss (0차원 대표 스칼라)
목적 2
레이어 간 행렬곱 규격 매칭 (차원 늘리기)

시스템적 필요에 의해 데이터 값은 동일하지만 다음 신경망 모듈(Embedding, RNN 등) 입구 규격에 맞추어 차원을 늘려 포장(Unsqueeze / Reshape)한다.

① 신경망 입구 규격 맞춤 포장
단일 토큰 값 15 (0차원) ➔ unsqueeze(0) ➔ [15] (1차원) ➔ unsqueeze(0) ➔ [[15]] (2차원 [Batch, Seq] 입력 규격 완료)
② 차원 강제 규격 주입 이유
PyTorch 내부 nn.Embedding, nn.RNN 등의 모듈은 대괄호 []가 씌워진 특정 차원 형상만 입력을 수용하기 때문이다.

3. 3차원 텐서 [2, 3, 4] 슬라이싱 & 연산 체험 시뮬레이터

💡 3차원 텐서 [2, 3, 4] 축 매핑 명세 총 24개 노드
dim=0 배치 크기 (Batch = 2)
동시 처리 문장 2개 (배치 0, 1)
dim=1 시퀀스 길이 (Seq = 3)
문장당 토큰 3개
dim=2 단어장/피처 (Vocab = 4)
단어당 어휘 점수 4개
📋 원본 입력 데이터 정의 및 PyTorch 선언 
tensor = torch.tensor([
  [[ 4.0,  1.0,  3.0,  2.0],
   [ 5.0,  8.0,  6.0,  7.0],
   [ 9.0, 10.0, 12.0, 11.0]],  # 배치 0 (문장 1의 단어별 점수판)
  
  [[ 3.0,  2.0,  5.0,  4.0],
   [ 6.0,  7.0,  9.0,  8.0],
   [13.0, 11.0, 10.0, 12.0]]   # 배치 1 (문장 2의 단어별 점수판)
], dtype=torch.float32)
Tensor [2, 3, 4] ➡️ 모든 24개 값 (전체 압축)
입력 SHAPE
[2, 3, 4]
출력 SHAPE
[] (스칼라)
크기
0차원
🔢 수학 연산식 & 연산 결과
연산 수식 & 계산 : t.mean() = (총합 168) / 24 = 7.0
출력 텐서 (Tensor Output) :
7.0 (0차원 스칼라)
💡 연산 원리
3개 축의 모든 24개 데이터 원소를 싹 평균 내어 대표 오차 0차원 스칼라 값 (7.0)으로 압축합니다.
🎓 현실의 의미
배치 전체, 시퀀스 전체의 모든 오차값들을 한 덩어리로 융합하여 평균을 구한 결과물이다.
• 실제 활용 : 학습 역전파(Backpropagation) 직전에 모델의 전체 오차 대표값 딱 1개를 계산하여 모델 최적화 지표로 활용한다.
• 직관적 이해 : 2개 문장(Batch=2) 내의 3개 단어(Seq=3)들이 가진 4개 단어장(Vocab=4) 값들(총 24개)을 축 구분 없이 싹 평균 내어, 전체 데이터의 종합 평균 딱 1개만 남겨 압축한다.
• 핵심 용도 : 학습을 위한 최종 오차 전파

4. 1문장(Batch=1) 인코더 내 텐서 차원 변화

인코더(Encoder)의 주 역할은 전체 입력 문장을 통째로 읽어 단 하나의 고정된 크기의 벡터(문맥 벡터, Context Vector)로 압축하는 것이다. 입력된 1차원 토큰 ID 시퀀스는 임베딩과 RNN을 거치면서 차원이 순차적으로 확장되며 문장의 의미 정보를 축적한다.

💡 인코더 차원 변화 해설
  • 입력 ID 시퀀스 : "나는 학교에 간다."의 5개 토큰에 대응하는 1차원 텐서 [5]가 인코더에 들어온다.
  • Embedding : 토큰을 고차원 실수의 벡터 표현으로 변경해 2차원 [5, 768]로 확장한다.
  • nn.RNN : 시퀀스를 따라 순차적으로 정보들을 누적 연산하며 최종적으로 모든 단어의 은닉 상태를 묶은 hidden_states [5, 1024]와 마지막 시퀀스 단계의 최종 요약 상태인 문맥 벡터 context_vector (h_n) [1, 1024]로 출력 분기한다.

5. 1문장(Batch=1) 디코더 내 텐서 차원 변화

디코더(Decoder)의 RNN 루프는 인코더의 최종 요약 은닉 상태인 문맥 벡터(encoder h_n)를 초기 기억(h_0)으로 주입받아 동작한다. 매 시점 예측된 output_token은 단어장 공간의 점수(logit)를 거치고 argmax로 디코딩된 후, 다음 시점의 입력으로 순환 피드백된다.

💡 디코더 차원 변화 해설
  • 초기 기억 주입 : 인코더의 최종 context_vector (h_n) [1, 1024]가 디코더 RNN의 초기 기억 h_0로 입력되어 문맥을 전달받는다.
  • Logit & Argmax : RNN 출력이 Linear 레이어를 거쳐 전체 단어장 확률인 2차원 logit [1, 30000]이 되고, squeeze() 후 argmax()를 통해 0차원 스칼라 Token ID '15'를 선출한다.
  • 순환 피드백 : 선출된 정답 단어는 unsqueeze(0)를 거쳐 2차원 output_token [1, 1] 규격으로 포장된 후, 다음 시점(t+1)의 입력 토큰으로 되돌아간다.
