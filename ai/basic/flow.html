신경망 아키텍처의 진화 과정

Linear에서 ViT까지: 정보 연결 방식의 역사

🗺️ 아키텍처 진화 로드맵 (클릭 시 상세 영역으로 부드럽게 이동)
1
Linear Layer - 기본 선형 변환

💡 왜 나왔는가?

입출력 데이터 간의 매핑 연결 필요
기본적인 선형 차원 변환 수행
가중치(Weight)와 편향(Bias) 자동 학습 가능

⚙️ 어떻게 작동하는가?

수식: y = Wx + b
입력 벡터에 가중치 가중 합산(행렬 곱셈) 수행
최종 가중합에 편향을 더해 출력 노드로 전달

✗ 문제점 및 한계

선형 변환만 표현할 수 있어 복잡한 관계 학습 한계
아무리 깊게 쌓아도 결국 하나의 Linear Layer와 수학적으로 동일
2
MLP - 활성화 함수로 비선형성 추가

💡 왜 나왔는가?

선형 모델의 결정적 표현 한계 극복
고차원 및 비선형 경계면을 갖는 복잡한 함수 표현 가능
계층화된 층을 통한 데이터의 유용한 특징 자동 추출

⚙️ 어떻게 작동하는가?

Linear Layer와 활성화 함수(ReLU 등)를 교대로 적층
층을 깊게 쌓아 모델의 수용력(Capacity)을 비약적으로 확장
역전파(Backpropagation) 알고리즘을 이용해 가중치 업데이트

✗ 문제점 및 한계

입력 데이터의 가로 너비(길이)가 고정되어야 함
시간의 흐름이나 선후 관계를 모르는 독립 데이터 처리 형태
텍스트나 오디오와 같은 시퀀스(Sequence) 처리 불가
3
RNN - 순환 연결로 시간 메모리 추가

💡 왜 나왔는가?

텍스트, 시각 프레임 등 가변 길이 시퀀스 처리 필요
시간 경과에 따른 맥락과 역사적 과거 정보 보존 요구
시계열, 자연어 등 순서가 핵심인 데이터의 구조 학습

⚙️ 어떻게 작동하는가?

수식: h(t) = f(x(t), h(t-1))
시간 축에 따라 데이터를 순차적으로 연산 처리
이전 타임스텝의 은닉 상태(Hidden State)를 다음 연산의 입력으로 반복 수용

✗ 문제점 및 한계

순차적 연산 특징으로 인해 GPU 대규모 병렬 학습이 불가 (학습 지체)
시퀀스가 길어질수록 극단적인 기울기 소실(Vanishing Gradient)로 과거 정보를 망각함
4
CNN - 지역 필터로 공간 구조 인식

💡 왜 나왔는가?

이미지 데이터 고유의 2차원 공간 구조 반영이 필요함
전체 픽셀을 개별 연결(MLP)하면 연산량이 폭증하는 단점 해결
가까운 이웃 픽셀 간의 물리적 지역 특징 탐지

⚙️ 어떻게 작동하는가?

3×3 등의 소형 공유 필터(커널)가 이미지를 훑으며 합성곱(Convolution) 연산 수행
위치에 상관없이 동일 패턴을 추출해 내는 가중치 공유(Weight Sharing)
Pooling 레이어를 통해 공간 해상도를 의도적으로 압축/요약

✗ 문제점 및 한계

필터 수용장(Receptive Field) 크기가 고정되어 먼 거리 픽셀의 상호 관계를 포착하기 어려움
자연어와 같은 1차원 순차 구조 데이터에 그대로 적용 시 비자연스러움
5
Attention - 전역 동적 가중치 연산

💡 왜 나왔는가?

시퀀스 데이터 내 모든 위치 간의 직접적인 상호작용 모델링 필요
고정된 필터 범위에 얽매이지 않는 동적인 전역 문맥 매핑 필요
순차 종속성을 없애 초거대 병렬 계산 학습이 가능하도록 유도

⚙️ 어떻게 작동하는가?

Query(질의)와 Key(후보) 벡터 간의 내적 연산으로 유사도 계산
유사도 점수를 Softmax 처리하여 확률적 주의(Attention) 가중치 획득
Value(실제 정보) 벡터들에 가중치를 곱해 가중합하여 출력 벡터 생성

✓ 해결된 포인트 및 강점

✓ 거리에 무관하게 한 번에 문맥 정보 추출 (소실 없는 장거리 학습)
✓ 고정 필터가 아닌, 들어온 입력에 따라 실시간으로 변하는 가중치 적용
6
Transformer - Attention 기반 전역 아키텍처

💡 왜 나왔는가?

RNN을 완전히 제거하여 병렬 처리가 극대화된 통합 번역 아키텍처 구현
초거대 파라미터 학습 환경(LLM)을 견인할 초석 아키텍처 필요
문맥을 입체적으로 쪼개 해석하는 Multi-Head 방식 적용

⚙️ 어떻게 작동하는가?

순서 정보를 명시하기 위해 입력에 포지셔널 인코딩(Positional Encoding) 결합
Multi-Head Self-Attention 및 Feed-Forward 연산을 스택으로 적층
인코더-디코더 교차 어텐션을 통해 고화질 번역 및 생성 연산 실행

✗ 문제점 및 한계

입력 길이(N)의 제곱에 비례하는 연산 복잡도 O(N²)로 리소스 급증
텍스트 외 2차원 고해상도 이미지 공간 정보의 효율적 처리에 미흡
7
ViT (Vision Transformer) - 컴퓨터 비전의 Transformer 대통합

💡 왜 나왔는가?

이미지 처리의 표준이었던 CNN의 고정 수용장 한계를 극복하고 이미지 전역의 시각적 맥락을 통합적으로 해석하기 위함
자연어(NLP)와 컴퓨터 비전(CV) 분야에서 서로 다르게 발전하던 아키텍처를 하나(Transformer)로 천하통일
CNN 고유의 지역성 가설(Inductive Bias)을 최소화하여 대규모 데이터셋 학습 시 CNN의 한계 성능을 압도적으로 능가

⚙️ 어떻게 작동하는가?

2차원 이미지를 일정한 크기(예: 16×16)의 바둑판 격자 패치들로 잘라 1차원 플래튼 벡터 시퀀스로 정렬
잘려진 이미지 패치들을 리니어 레이어를 거치게 하여 토큰 크기로 투영(Linear Projection) 및 패치 임베딩 생성
패치 간의 2차원 위치 정보를 복원하기 위해 포지션 임베딩을 가산하고 트랜스포머 인코더(Transformer Encoder) 블록 통과
분류 목적을 위해 첫 토큰 자리에 추가한 `[CLS]` 토큰의 최종 출력 임베딩을 MLP Head에 연결하여 타겟 클래스 예측

✓ 해결된 포인트 및 강점

✓ **전역 관계 추론**: 첫 레이어부터 이미지의 극단적 왼쪽 아래와 오른쪽 위 픽셀 패치 간의 전역 상관관계를 한 번에 포착
✓ **멀티모달 대통합**: 텍스트, 이미지, 사운드 등 모달리티 종류와 상관없이 모두 동일한 트랜스포머 블록으로 단일 처리 규격화
✓ **경이로운 확장성 (Scaling Law)**: 모델 크기와 데이터 볼륨이 커질수록 성능이 임계점 없이 무한히 우상향하는 가속 학습 구현
📊 핵심 진화 패턴 총정리
1 ➔ 2 진화: 선형 변환의 표현적 한계 해결 ➔ 비선형 활성화 함수(ReLU) 추가
2 ➔ 3 진화: 고정 너비 처리의 한계 해결 ➔ 시간축 이전 맥락 전달용 순환 상태 메모리 추가
2 ➔ 4 진화: 공간 기하학적 형태 무시 해결 ➔ 2차원 지역 가중치 공유 필터(CNN) 도입
3 ➔ 5 진화: 순차 처리 병렬화 한계 ➔ 전역 동적 가중치 기법(Attention) 수립
5 ➔ 6 진화: 메모리 보조 역할 탈피 ➔ Attention을 핵심 스택으로 전형화(Transformer)
6 & 4 ➔ 7 진화: CNN의 공간적 필터 한계 격파 ➔ 비전 영역을 Transformer로 통일(ViT)
🔑 아키텍처 진화의 통찰:
각 세대의 신경망 아키텍처 진화는 근본적으로 "정보를 서로 어떻게 연결하고 전달할 것인가?"에 대한 한계를 격파해 온 여정입니다.

Linear(직접 1대1 매핑) ➔ MLP(계층 간 매핑) ➔ RNN(시간 축 순차 매핑) / CNN(공간 지역 공유 매핑) ➔ Attention(전역 맥락 동적 가중합) ➔ Transformer(전역 어텐션 스택 아키텍처) ➔ ViT(비전 영역 전역 어텐션 대통합)로 끊임없이 유연성과 구조적 한계를 보완하며 발전해 왔습니다.
