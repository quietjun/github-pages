신경망 아키텍처의 진화 과정

Linear에서 ViT까지: 정보 연결 방식의 역사

1
Linear Layer - 기본 선형 변환
왜 나왔는가?
입출력 데이터 노드 간의 1대1 매핑 연결을 형성하여 가장 원초적인 정보를 변환하고 가공하기 위함
입력 차원을 출력 차원으로 정형화하여 상이한 데이터 형태 간의 물리적인 선형 크기를 정합하고 연결
데이터 학습의 시발점이 되는 최적의 가중치(Weight) 매트릭스와 바이어스(Bias) 벡터를 스스로 찾아 최적화 가능
어떻게 작동하는가?
선형 결합 수식 y = Wx + b 에 기반하여 모든 입력 값에 가중치 매트릭스 곱 연산 수행
다차원 입력 벡터를 내적 합산하고, 가중값들의 총합에 최종 보정용 상수인 편향(Bias)을 더함
오차 역전파 과정에서 경사하강법을 통해 가중치 W와 b를 끊임없이 보정 및 최적 경로 학습
문제점 및 한계
단순 행렬 연산이기 때문에 비선형(Non-linear) 관계나 꺾인 경계면을 가지는 복잡한 함수적 매핑을 학습 불가
아무리 두껍게 쌓아도 행렬 곱의 특성상 결국 하나의 단일 선형 연산과 수학적으로 동일하여 깊이의 이점이 무색
⚡ 발전 방향: 단순 선형성을 타파할 비선형 활성화 함수 필요
2
MLP - 활성화 함수로 비선형성 추가
왜 나왔는가?
단순 단층 선형 모델이 지닌 논리적 배타합(XOR) 문제 등 표현력의 한계를 근본적으로 타파하기 위함
복잡한 비선형 경계면을 유연하게 학습하여 데이터의 곡선적이고 고밀도 분류 경계를 온전히 표현
얕고 평평한 네트워크 구조에서 탈피하여, 층이 깊어질수록 데이터의 유용하고 추상화된 특징을 계층별로 자동 추출
어떻게 작동하는가?
각 Linear Layer 사이에 ReLU, Sigmoid 등의 비선형 활성화 함수를 교대로 적층
활성화 함수를 통해 인위적으로 선형 출력을 꺾어주어 층을 깊게 쌓을수록 모델의 표현 한계력(Capacity)을 극대화
오차가 뒤에서부터 역방향으로 전파되는 역전파 메커니즘을 통해 다층의 전체 가중치 파라미터를 점진적으로 갱신
문제점 및 한계
입력으로 고정된 가로 너비(피처 크기)만 수용할 수 있어 입력 데이터의 형상이 늘 일정하게 유지되어야 함
데이터 간의 순서나 시간의 흐름, 문맥적 순차 관계를 인지하지 못하고 매 입력을 개별 독립 사건으로 인지
오디오나 자연어 등 길이를 예측할 수 없는 가변 길이 시퀀스(Sequence) 데이터를 연속적으로 처리하는 데 한계
⚡ 발전 방향: 문맥과 역사를 기억할 수 있는 메모리 구조 필요
3
RNN - 순환 연결로 시간 메모리 추가
왜 나왔는가?
시계열 신호나 자연어처럼 시간 흐름에 따라 순차적으로 생성되는 가변 길이 데이터를 역동적으로 학습하기 위함
이전 타임스텝의 정보가 현재의 의사결정에 긴밀한 영향을 미치는 문맥과 역사적 맥락 정보를 고스란히 보존
음성 인식, 기계 번역 등 입력과 출력의 시퀀스 길이가 가변적이고 전후 맥락이 의미를 결정하는 도메인 처리
어떻게 작동하는가?
순환 구조 점화식 h(t) = f(x(t), h(t-1)) 에 기반하여 순차 루프 연산 수행
매 시점 들어오는 새로운 입력 정보와 이전 시점에 업데이트된 은닉 상태(Hidden State)를 함께 융합하여 입력
타임스텝별 파라미터를 완벽히 공유(Shared Weights)하여 가변적 길이 데이터 속에서도 일관된 가중치 연산 실행
문제점 및 한계
순서에 의존해 이전 시점 계산이 끝나야 다음 시점을 연산하므로, GPU의 장점인 대규모 병렬 계산 처리가 불가
문장이 길어질수록 먼 과거의 기울기가 지수적으로 소실되는 기울기 소실(Vanishing Gradient)로 인해 조기 망각 발생
초반부 정보가 후반부로 가면서 극도로 희석되어 먼 거리의 단어 관계를 해석하는 장기 의존성 문제를 노출
⚡ 발전 방향: 순차 종속성을 없애고 전역 연결과 공간 병렬 처리가 가능한 구조 필요
4
CNN - 지역 필터로 공간 구조 인식
왜 나왔는가?
이미지가 지닌 고유의 2차원 공간적 인접 구조와 위치 변동에도 변하지 않는 시각 특징(Translation Invariance) 학습
전체 픽셀 노드를 MLP처럼 단순 플래튼하여 모두 연결할 시 발생하는 천문학적인 연산 파라미터 폭증 문제 해결
가로·세로로 가까운 이웃 픽셀들 사이의 질감, 경계선, 모서리 등 물리적인 공간 패턴 정보를 고스란히 획득
어떻게 작동하는가?
작은 격자 크기의 공유 필터(커널)를 정의하고, 입력 이미지 위를 슬라이딩하며 국소적인 합성곱(Convolution) 연산 수행
이미지의 어느 부위에서 특징이 감지되든 동일 필터로 식별하게 만드는 가중치 공유(Parameter Sharing) 메커니즘 작동
Pooling 레이어를 사용해 이미지의 해상도 크기를 축소함으로써 사소한 픽셀 위치 변화에 강인한 특징만 간추려 요약
문제점 및 한계
합성곱 필터의 윈도우 크기(Receptive Field)가 태생적으로 고정되어 있어 전체 화면 수준의 초장거리 맥락을 즉시 포착 한계
2차원 그리드 구조 데이터에 완벽 특화되어 있어, 1차원 자연어나 텍스트 등 문맥 순차 관계 모델링 시 다소 작위적인 구조 형성
⚡ 발전 방향: 필터 크기에 구애받지 않고 모든 위치를 한 번에 동적으로 잇는 연결 방식 필요
5
Attention / Transformer - 전역 동적 가중치
왜 나왔는가?
시퀀스 내의 두 요소가 아무리 멀리 떨어져 있어도 거리 제약 없이 단숨에 문맥적인 상호작용을 포착하기 위함
고정된 필터나 이전 상태에 얽매이지 않고, 들어온 문장 전체의 상관관계에 따라 동적으로 가중치가 할당되는 연결 구조
순차적 루프 구조를 배제하여 수천만 개의 토큰을 동시에 일괄 처리할 수 있는 대규모 초병렬 학습 실현
어떻게 작동하는가?
입력 벡터들로부터 Query(질의), Key(후보 키), Value(실제 정보)라는 3가지 고차원 학습 벡터 공간 생성
Query와 모든 Key 간의 행렬 곱 유사도를 연산하고, Softmax를 통해 각 요소 간의 연관 정도를 나타내는 주의 점수 획득
획득한 연관도 가중치 점수를 Value 벡터에 가중 곱한 뒤 모두 더하여 문맥 정보를 압축한 최종 맥락 표현 벡터 반환
해결된 포인트 및 강점
✓ **무제한 수용장**: 거리 소실(Vanishing) 현상 없이 문장 시작 단어와 끝 단어 간의 전역적 의미적 상호작용 포착
✓ **완전 병렬화**: 타임스텝의 종속성을 해체하여 수만 대의 GPU에서 LLM 모델의 대규모 고속 분산 학습 가능
✓ **문맥 맞춤 동적 연결**: 고정된 커널 가중치 대신 들어오는 정보의 흐름에 따라 매번 달라지는 똑똑한 의미 연산 실현
⚡ 발전 방향: Attention을 이미지 영역으로 확장하여 공간적 한계를 깨부수는 ViT(Vision Transformer) 등장
6
ViT (Vision Transformer) - 컴퓨터 비전의 Transformer 대통합
왜 나왔는가?
이미지 처리의 표준이었던 CNN의 고정 수용장 한계를 극복하고 이미지 전역의 시각적 맥락을 통합적으로 해석하기 위함
자연어(NLP)와 컴퓨터 비전(CV) 분야에서 서로 다르게 발전하던 아키텍처를 하나(Transformer)로 천하통일
CNN 고유의 지역성 가설(Inductive Bias)을 최소화하여 대규모 데이터셋 학습 시 CNN의 한계 성능을 압도적으로 능가
어떻게 작동하는가?
2차원 이미지를 일정한 크기(예: 16×16)의 바둑판 격자 패치들로 잘라 1차원 플래튼 벡터 시퀀스로 정렬
잘려진 이미지 패치들을 리니어 레이어를 거치게 하여 토큰 크기로 투영(Linear Projection) 및 패치 임베딩 생성
패치 간의 2차원 위치 정보를 복원하기 위해 포지션 임베딩을 가산하고 트랜스포머 인코더(Transformer Encoder) 블록 통과
분류 목적을 위해 첫 토큰 자리에 추가한 `[CLS]` 토큰의 최종 출력 임베딩을 MLP Head에 연결하여 타겟 클래스 예측
해결된 포인트 및 강점
✓ **전역 관계 추론**: 첫 레이어부터 이미지의 극단적 왼쪽 아래와 오른쪽 위 픽셀 패치 간의 전역 상관관계를 한 번에 포착
✓ **멀티모달 대통합**: 텍스트, 이미지, 사운드 등 모달리티 종류와 상관없이 모두 동일한 트랜스포머 블록으로 단일 처리 규격화
✓ **경이로운 확장성 (Scaling Law)**: 모델 크기와 데이터 볼륨이 커질수록 성능이 임계점 없이 무한히 우상향하는 가속 학습 구현
⚡ 발전 방향: 모든 형태의 미디어(텍스트, 이미지, 음성)를 하나의 아키텍처로 처리하는 초거대 멀티모달 통합
📊 핵심 진화 패턴 총정리
1 ➔ 2 진화: 선형 변환의 표현적 한계 해결 ➔ 비선형 활성화 함수(ReLU) 추가
2 ➔ 3 진화: 고정 너비 처리의 한계 해결 ➔ 시간축 이전 맥락 전달용 순환 상태 메모리 추가
3 ➔ 4 진화: 순차 처리 병렬화 한계 ➔ 공간 정보 학습용 지역 합성곱 필터 도입
4 ➔ 5 진화: 필터 크기 고정 및 거리적 한계 해결 ➔ 전역 동적 주의 가중치(Attention) 연결
5 ➔ 6 진화: 자연어 전용 아키텍처의 한계 극복 ➔ 비전 영역 대통합 및 범용 인코더(ViT) 실현
🔑 아키텍처 진화의 통찰:
각 세대의 신경망 아키텍처 진화는 근본적으로 "정보를 서로 어떻게 연결하고 전달할 것인가?"에 대한 한계를 격파해 온 여정입니다.

Linear(직접 1대1 매핑) ➔ MLP(계층 간 매핑) ➔ RNN(시간 축 순차 매핑) ➔ CNN(공간 지역 공유 매핑) ➔ Attention(전역 맥락 동적 가중합 매핑) ➔ ViT(비전 영역 전역 어텐션 대통합)로 끊임없이 유연성과 구조적 한계를 보완하며 발전해 왔습니다.
