신경망 아키텍처의 진화 과정

Linear에서 Attention까지: 정보 연결 방식의 역사

1
Linear Layer - 기본 선형 변환
왜 나왔는가?
입출력 데이터 간의 매핑 연결 필요
기본적인 선형 차원 변환 수행
가중치(Weight)와 편향(Bias) 자동 학습 가능
어떻게 작동하는가?
수식: y = Wx + b
입력 벡터에 가중치 가중 합산(행렬 곱셈) 수행
최종 가중합에 편향을 더해 출력 노드로 전달
문제점 및 한계
선형 변환만 표현할 수 있어 복잡한 관계 학습 한계
아무리 깊게 쌓아도 결국 하나의 Linear Layer와 수학적으로 동일
⚡ 발전 방향: 단순 선형성을 타파할 비선형 활성화 함수 필요
2
MLP - 활성화 함수로 비선형성 추가
왜 나왔는가?
선형 모델의 결정적 표현 한계 극복
고차원 및 비선형 경계면을 갖는 복잡한 함수 표현 가능
계층화된 층을 통한 데이터의 유용한 특징 자동 추출
어떻게 작동하는가?
Linear Layer와 활성화 함수(ReLU 등)를 교대로 적층
층을 깊게 쌓아 모델의 수용력(Capacity)을 비약적으로 확장
역전파(Backpropagation) 알고리즘을 이용해 가중치 업데이트
문제점 및 한계
입력 데이터의 가로 너비(길이)가 고정되어야 함
시간의 흐름이나 선후 관계를 모르는 독립 데이터 처리 형태
텍스트나 오디오와 같은 시퀀스(Sequence) 처리 불가
⚡ 발전 방향: 문맥과 역사를 기억할 수 있는 메모리 구조 필요
3
RNN - 순환 연결로 시간 메모리 추가
왜 나왔는가?
텍스트, 시각 프레임 등 가변 길이 시퀀스 처리 필요
시간 경과에 따른 맥락과 역사적 과거 정보 보존 요구
시계열, 자연어 등 순서가 핵심인 데이터의 구조 학습
어떻게 작동하는가?
수식: h(t) = f(x(t), h(t-1))
시간 축에 따라 데이터를 순차적으로 연산 처리
이전 타임스텝의 은닉 상태(Hidden State)를 다음 연산의 입력으로 반복 수용
문제점 및 한계
순차적 연산 특징으로 인해 GPU 대규모 병렬 학습이 불가 (학습 지체)
시퀀스가 길어질수록 극단적인 기울기 소실(Vanishing Gradient)로 과거 정보를 망각함
⚡ 발전 방향: 순차 종속성을 없애고 전역 연결과 공간 병렬 처리가 가능한 구조 필요
4
CNN - 지역 필터로 공간 구조 인식
왜 나왔는가?
이미지 데이터 고유의 2차원 공간 구조 반영이 필요함
전체 픽셀을 개별 연결(MLP)하면 연산량이 폭증하는 단점 해결
가까운 이웃 픽셀 간의 물리적 지역 특징 탐지
어떻게 작동하는가?
3×3 등의 소형 공유 필터(커널)가 이미지를 훑으며 합성곱(Convolution) 연산 수행
위치에 상관없이 동일 패턴을 추출해 내는 가중치 공유(Weight Sharing)
Pooling 레이어를 통해 공간 해상도를 의도적으로 압축/요약
문제점 및 한계
필터 수용장(Receptive Field) 크기가 고정되어 먼 거리 픽셀의 상호 관계를 포착하기 어려움
자연어와 같은 1차원 순차 구조 데이터에 그대로 적용 시 비자연스러움
⚡ 발전 방향: 필터 크기에 구애받지 않고 모든 위치를 한 번에 동적으로 잇는 연결 방식 필요
5
Attention / Transformer - 전역 동적 가중치
왜 나왔는가?
데이터 소스 내 모든 위치 간의 직접적인 상호작용 모델링 필요
문장 문맥에 따라 동적으로 가중치가 변하는 스마트 연결 요구
순차 종속성을 없애 초거대 병렬 계산 학습이 가능하도록 유도
어떻게 작동하는가?
Query(질의)와 Key(후보 열쇠) 벡터 간의 연산을 통해 유사도 획득
유사도 점수를 Softmax 처리하여 정규화된 주의(Attention) 가중치 결정
Value(후보 실제 정보) 벡터들에 가중치를 곱해 합산하여 출력 벡터 생성
해결된 포인트 및 강점
✓ 거리에 무관하게 한 번에 문맥 정보 추출 (소실 없는 장거리 학습)
✓ 시퀀스 의존성을 완전 탈피하여 대규모 분산/병렬 고속 학습 성립
✓ 고정 필터가 아닌, 들어온 입력에 따라 변하는 전역 동적 가중치 적용
🎯 게임 체인저 (Game Changer) 병렬 학습 가능 + 무제한 장거리 의존성 + 문맥 맞춤 동적 연결 특징의 결합은 현대 수십억 파라미터 규격의 LLM(대형 언어 모델) 스케일링을 가속한 핵심 원동력이 되었습니다.
📊 핵심 진화 패턴 총정리
1 ➔ 2 진화: 선형 변환의 표현적 한계 해결 ➔ 비선형 활성화 함수(ReLU) 추가
2 ➔ 3 진화: 고정 너비 처리의 한계 해결 ➔ 시간축 이전 맥락 전달용 순환 상태 메모리 추가
3 ➔ 4 진화: 순차 처리 병렬화 한계 ➔ 공간 정보 학습용 지역 합성곱 필터 도입
4 ➔ 5 진화: 필터 크기 고정 및 거리적 한계 해결 ➔ 전역 동적 주의 가중치(Attention) 연결
🔑 아키텍처 진화의 통찰:
각 세대의 신경망 아키텍처 진화는 근본적으로 "정보를 서로 어떻게 연결하고 전달할 것인가?"에 대한 한계를 격파해 온 여정입니다.

Linear(직접 1대1 매핑) ➔ MLP(계층 간 매핑) ➔ RNN(시간 축 순차 매핑) ➔ CNN(공간 지역 공유 매핑) ➔ Attention(전역 맥락 동적 가중합 매핑)으로 끊임없이 유연성과 구조적 한계를 보완하며 발전해 왔습니다.
