Spring Boot 호스팅 가이드

서버 사양: VM.Standard.A1.Flex (ARM 기반)
리소스: 2 OCPU / 12GB RAM / 47GB+ Disk (무료 한도 내 최적 사양)

1. ARM 인스턴스 생성 및 네트워크 설정

  1. 컴퓨팅 > 인스턴스 > 인스턴스 생성
  2. 이미지: Canonical Ubuntu 22.04 선택
  3. 셰이프: VM.Standard.A1.Flex (Ampere ARM) 선택
    • OCPU: 2 / RAM: 12GB 로 설정
  4. 네트워킹: 공용 IPv4 주소 할당 반드시 체크
  5. SSH 키: 전용 키 저장 및 공용 키 저장 클릭하여 파일 보관
  6. 보안 목록(Ingress Rules) 추가:
    • 8080 (Spring Boot), 80 (HTTP), 3306 (MySQL) 포트 개방

2. 서버 접속 및 초기 환경 설정

내 컴퓨터의 터미널(CMD/PowerShell/Mac Terminal)에서 접속합니다.

# SSH 접속 (키 권한 설정 필수 - Linux/Mac)
chmod 400 private_key.key
ssh -i private_key.key ubuntu@[서버_공용_IP]

가상 메모리(Swap) 설정 (12GB RAM이지만 안정성을 위해 권장)

sudo fallocate -l 4G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

3. Java 21 및 MySQL 설치

JDK 21 설치

sudo apt update
sudo apt install openjdk-21-jdk -y
java -version

MySQL 설치 및 계정 설정

sudo apt install mysql-server -y
sudo mysql

-- MySQL 내부 쿼리
CREATE DATABASE ssafy_db;
CREATE USER 'quietjun'@'%' IDENTIFIED BY 'dmstj@0205M';
GRANT ALL PRIVILEGES ON ssafy_db.* TO 'quietjun'@'%';
FLUSH PRIVILEGES;
EXIT;

4. 포트 리다이렉션 (Nginx 없이 80포트 연결)

사용자가 도메인 뒤에 :8080을 붙이지 않아도 되도록 설정합니다.

# 80번 포트로 오는 요청을 8080으로 전달
sudo iptables -t nat -I PREROUTING -p tcp --dport 80 -j REDIRECT --to-port 8080
sudo iptables -I INPUT -p tcp --dport 80 -j ACCEPT

# 방화벽 설정 저장
sudo apt install iptables-persistent -y
sudo netfilter-persistent save

5. 가비아 도메인 연결

  • 가비아 DNS 설정: 타입 A, 호스트 @, 값에 서버 공용 IP 입력
  • 확인: 이제 브라우저에서 http://도메인으로 접속 시 Spring Boot(8080)로 자동 연결됩니다.

6. 애플리케이션 상시 가동 (systemd)

/etc/systemd/system/myapp.service 파일을 생성하여 관리합니다.

[Unit]
Description=Spring Boot Application
After=network.target

[Service]
User=ubuntu
ExecStart=/usr/bin/java -jar /home/ubuntu/app.jar
SuccessExitStatus=143
Restart=always

[Install]
WantedBy=multi-user.target
sudo systemctl enable myapp
sudo systemctl start myapp
주의: ARM 아키텍처(Aarch64)를 사용하므로, 만약 Native 라이브러리를 사용한다면 빌드 시 ARM용 바이너리가 포함되었는지 확인해야 합니다. 일반적인 Spring Boot 앱은 문제없이 작동합니다.
